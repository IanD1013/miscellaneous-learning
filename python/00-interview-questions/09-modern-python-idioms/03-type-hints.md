类型提示（type hint）让你可以标注一个变量、参数或返回值预期持有什么类型。
它们在 PEP 484 中被标准化，并从 Python 3.5 开始稳步发展。
首先要理解的是：Python 在程序运行时不会检查或强制执行这些提示。
它们是供人类、编辑器和独立的检查工具阅读的文档。
面试官会问到类型提示，因为它们能表明你是否能读懂一个带类型的代码库，以及你是否理解提示只是一种承诺，而不是一种保证。

### 标注变量、参数和返回值

参数提示写在名字后面，用冒号隔开。
返回值提示写在参数列表后面，用箭头标出。

```python
def greet(name: str, times: int) -> str:
    return (name + " ") * times
```

单独的变量也可以被标注，可以带赋值，也可以不带。

```python
count: int = 0
total: float          # 只有标注，还没有绑定值
```

这些标注存储在函数的 `__annotations__` 中，但除此之外不会改变代码的运行方式。
没有返回值的函数被标注为 `-> None`，意思是它返回 `None`（每个没有显式 return 的函数都是如此）。

```python
def log(message: str) -> None:
    print(message)
```

### 内置泛型语法

容器提示会写出容器的名字，并在方括号中写出其元素的类型。
从 Python 3.9 开始，你可以直接使用小写的内置类型，所以你不再需要从 `typing` 中导入 `List`、`Dict` 之类的东西。

```python
names: list[str]              # 一个字符串列表
ages: dict[str, int]          # 键是 str，值是 int
pair: tuple[int, str]         # 恰好两个元素，先是一个 int，然后是一个 str
row: tuple[int, ...]          # 一个包含任意数量 int 的元组
```

这两种 `tuple` 形式是不同的。
`tuple[int, str]` 是一个固定长度的元组，其中每个位置都有它自己的类型。
`tuple[int, ...]` 使用一个字面量省略号（ellipsis），表示一个长度未知、每个元素都是 `int` 的元组。

在 Python 3.8 中，小写形式不支持下标，所以较老的代码会改为从 `typing` 中导入 `List`、`Dict`、`Tuple`。
认得这种风格仍然是值得的，但新代码应该使用内置类型。

### 用 X | None 表示可选值

一个可能是真实值也可能是 `None` 的值，用联合（union）运算符来书写，从 Python 3.10 开始可以作为类型提示使用。

```python
def find(key: str) -> str | None:
    ...
```

这个 `str | None` 是较老代码中写作 `Optional[str]`（从 `typing` 导入）的现代写法。
两者的意思相同：这个值要么是一个 `str`，要么是 `None`。
`Optional[str]` 并不表示这个参数是可选的或者有默认值；它只描述类型。
`|` 运算符也可以构建普通的联合类型，比如 `int | str`，用于可能是其中任一类型的值。

### 提示在运行时不会被强制执行

这是面试官最常考察的一点。
传入错误的类型并不会因为提示而抛出错误。

```python
def double(n: int) -> int:
    return n * 2

print(double("ab"))   # 'abab'  运行正常，提示不会引发 TypeError
```

提示写的是 `int`，但 Python 很乐意地把字符串做了乘法。
标注只是元数据；解释器从不会把参数与它进行比较。
如果你希望捕获类型错误，就要运行一个独立的静态检查器。

### 用 mypy 进行静态检查

`typing` 是存放类型工具的标准库模块，而 `mypy` 是最常用的静态类型检查器。
它在不运行程序的情况下读取你的标注，并报告不匹配之处。

```python
def add(a: int, b: int) -> int:
    return a + b

add("1", "2")   # mypy 会标记这里；Python 本身只会把它们拼接起来
```

类型提示的回报在于工具支持和可读性：编辑器能提供更好的自动补全和行内警告，审阅者能一眼看出意图，检查器能在代码运行之前捕获一类 bug。
这些都不会改变运行时的行为，运行时的行为与完全没有提示时一模一样。
