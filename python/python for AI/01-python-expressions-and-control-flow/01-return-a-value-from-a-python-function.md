Python 函数以 `def` 开头。
它的 `return` 语句会向调用它的代码提供一个结果。
下面这个函数返回一个包含单个文本值的列表：

```python
def fixed_label(value):
    return ["ready"]
```

`def` 用于引入定义，后面紧跟函数名 `fixed_label`。
圆括号内包含一个参数 `value`：这是在调用函数时所提供实参的名称。
这里不需要编写参数类型。
冒号标志着函数体的开始，即在调用期间运行的语句。

`return` 前面的四个空格将其置于该函数体内部。
Python 使用缩进来对语句进行分组，而不是使用花括号包围函数体。
请保持同一函数体内的语句对齐，并始终一致地使用空格。
这些代码行不需要分号。

`return` 会结束当前调用并返回其后的表达式。
在此处，方括号创建了一个包含一个元素的列表，该元素就是括号之间的值。
引号使 `"ready"` 成为一个字符串（即文本值）。
提供的初始代码使用了这种相同的单元素方括号模式；在更改括号内的内容时，请保留方括号。

定义函数会使其可用，而不会运行其函数体。
调用 `fixed_label(0)` 会提供 `0` 作为实参，并产生 `["ready"]`。
由于返回表达式包含字面文本，因此结果保持不变。
不带引号的参数名指代所提供的实参；而在该名称周围加上引号则会生成文本。

### 完成函数

完成 `wrap_value(value)`，使其返回一个包含原样不变实参的单元素列表。
保留所提供的函数名和参数。
输入可能是字符串、整数、布尔值或 `None`（Python 中表示空值的值）。
Python 中的两个布尔值拼写为 `True` 和 `False`。
这些提供的值可以原样放入方括号内，就像文本或数字一样。

初始代码目前对每个实参都返回 `[None]`。
将其固定元素替换为对实参的引用，同时保留值及其类型。
你不需要添加函数调用。

### 解答

```python
def wrap_value(value):
    return [value]
```
