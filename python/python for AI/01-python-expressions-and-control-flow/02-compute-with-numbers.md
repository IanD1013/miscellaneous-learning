使用 `=` 将值赋给变量。
Python 会对右侧的表达式求值，然后将该值赋予左侧的名称：

```python
count = 9
increased = count + 4
doubled = count * 2
whole_groups = count // 4
leftover = count % 4
```

这里 `increased` 是 `13`：`+` 将两个值相加。
`doubled` 是 `18`：`*` 将它们相乘。
赋值不需要类型声明或分号。
每一行都可以使用之前行中赋值的名称。
在函数内部，请将这些赋值缩进到与其 `return` 语句相同的级别。

`//` 执行整数除法（向下取整除法），对于整数输入，会将商向下取整为整数。
对于这些正数，`9 // 4` 得到 `2`，即完整的 4 的组数。
`%` 计算余数，因此 `9 % 4` 是 `1`。
这两个结果相吻合：`2 * 4 + 1` 重新构成了 `9`。
Python 先乘后加。
将此计算保持在整数范围内也适用于大整数，而不会四舍五入舍去任何剩余单位。

完成 `split_seconds(seconds)`。
它的参数是一个非负整数，表示以秒为单位的时间。
以每分钟 60 秒为基准，计算完整的分钟数以及在这些分钟之后剩余的秒数。
返回这两个整数，分钟在前，放在一个包含两个元素的列表中。

对于这种返回形式，方括号包含由逗号分隔的两个值：`return [3, 2]` 返回数对 `[3, 2]`。
将初始代码中的固定零替换为您计算出的值。
0 秒必须生成 0 分钟和 0 剩余秒；刚好整分钟的时间则没有剩余秒数。

### 解答

```python
def split_seconds(seconds):
    minutes = seconds // 60
    remainder = seconds % 60
    return [minutes, remainder]
```
