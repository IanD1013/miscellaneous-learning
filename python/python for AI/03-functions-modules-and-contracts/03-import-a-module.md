`import math` 可以使 Python 的标准 math 模块可用。
模块将相关的函数归拢在一个名称之下；其命名空间（namespace）就是你通过它访问的名称集合。

```python
import math

root = math.sqrt(81)
```

将 import 语句放在函数定义之前。
`math.sqrt` 中的点号用于从模块中选取 `sqrt`，括号则向其传入一个数字。
`sqrt` 返回非负平方根：`root` 是 `9.0`，因为九乘九等于 81。
它的参数必须是非负数。

你也可以直接导入某一个函数：

```python
from math import sqrt

root = sqrt(81)
```

`from` 指明要查找的模块名称；`import` 指明要引入到代码中的内容。
这种形式会创建名称 `sqrt`，因此调用时无需 `math.` 前缀。
但在阅读多个导入时，保留模块前缀可以使函数的来源更加清晰可见。

内置的 `round(value, 6)` 无需导入。
它的第二个参数将数字舍入到六位小数。
例如，`round(2.718281828, 6)` 返回 `2.718282`。
它返回的是一个数字，因此末尾的零不一定会显示。

对于距离，表达式 `math.sqrt(x * x + y * y)` 计算坐标平方和的平方根。
即使坐标为负数，平方也会使每一项变为非负数，从而使平方根拥有一个有效的参数。
若 `x = -6` 且 `y = 8`，则平方和为 100，距离为 `10.0`。

### 计算距离

完成 `distance_from_origin(x, y)`，返回从 `(0, 0)` 到 `(x, y)` 的非负距离，并保留六位小数。
上面的导入模式是实现该计算的一种方式；使用目前介绍的概念所实现的等效代码也均有效。

输入为有限整数或浮点数，每个数值的绝对值最大为 1,000,000。
零是有效输入，原点到自身的距离为 `0.0`。
超出此范围的输入不会传入该函数。

### 解答

```python
import math

def distance_from_origin(x, y):
    return round(math.sqrt(x * x + y * y), 6)
```
