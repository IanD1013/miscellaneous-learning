切片（slice）使用 `values[start:stop]` 来选取列表中的一个元素范围。
方括号内的冒号用于分隔两个边界：

```python
values = [12, 24, 36, 48]
part = values[1:3]
```

`part` 的值为 `[24, 36]`。
起始位置（start）是包含在内的：包含位置 `1`。
结束位置（stop）是不包含在内的：排除位置 `3`。
与返回单个元素的索引不同，切片会返回一个包含按原始顺序排列的所选元素的新列表。

通用形式 `[start:stop]` 允许你省略其中任意一个边界。
若没有 start，Python 会从位置 `0` 开始；若没有 stop，它会一直切片到末尾。
`values[:2]` 会选取前两个元素。
形式 `[:]` 则省略了两个边界，从而复制整个列表。
切片是一种选取前缀的安全方式，不会修改调用者的列表。
就地（in place）修改该列表可能会对仍然需要其原始内容的调用者造成意想不到的影响。

切片边界会被限制在可用范围内：`values[:20]` 会返回全部四个元素，而不会出现索引错误。
`values[:0]` 返回 `[]`，对空列表切片也会返回 `[]`。
负数的 stop 会从末尾向前倒数，因此当参数表示请求的数量时，需要对其进行单独处理。

### 获取前缀

完成 `take_prefix(values, count)`。
前缀是列表的开头部分。
输入为一个列表和一个整数 count。
按原始顺序返回其前 `count` 个元素。
请练习使用切片来进行选取。
若 count 为负数，返回 `[]`。
当 count 大于列表长度时，返回所有可用的元素。

### 解答

```python
def take_prefix(values, count):
    if count < 0:
        return []
    return values[:count]
```
