Python 提供了三种用值构建字符串的方式：f-string（现代的默认选择）、`str.format`，以及旧式的 `%` 运算符。
面试官希望看到你默认使用 f-string，理解格式规格迷你语言（format spec mini-language），并且知道旧风格仍然能带来什么好处。

### f-string

f-string 是以 `f` 为前缀的字符串字面量。
`{}` 中的任何内容都是一个在运行时求值的 Python 表达式，然后被转换为文本。

```python
name = "Ada"
age = 36
print(f"{name} is {age} years old")   # Ada is 36 years old
print(f"{age * 2}")                    # 72
print(f"{name.upper()}")               # ADA
```

表达式几乎可以是任何东西：函数调用、属性访问、索引、条件表达式。
f-string 会被立即求值，所以变量必须已经存在。

#### `=` 调试形式（3.8+）

在花括号中加上 `=` 会同时打印表达式文本和它的值。
这是一种无需重复输入名字就能快速记录日志的方式。

```python
x = 5
print(f"{x=}")          # x=5
print(f"{x * 2 =}")     # x * 2 =10
```

`=` 周围的空白会原样保留在输出中，这就是为什么 `{x * 2 =}` 在 `=` 前显示了一个空格。

#### 嵌套引号

在 Python 3.12 之前，你不能在 f-string 表达式中重复使用相同的引号字符。
从 3.12 开始解析器允许这样做，但为了保持可移植性，很多人仍然交替使用不同的引号风格。

```python
d = {"key": "value"}
print(f"{d['key']}")           # value（双引号 f-string 内使用单引号）
print(f"{d["key"]}")           # 在 3.12 中可以运行，在 3.11 及更早版本中失败
```

你还可以使用 `{{` 和 `}}` 来输出字面量花括号。

### `str.format` 和替换字段

`str.format` 早于 f-string 出现，在模板和数据分离的场景中仍然会出现（例如从配置中加载的模板）。

```python
"{} costs {}".format("apple", 0.5)        # apple costs 0.5
"{0} and {0}".format("hi")                 # hi and hi  （位置索引，可重复使用）
"{name}".format(name="Ada")                # Ada        （关键字字段）
"{p.x}".format(p=point)                    # 属性访问
"{0[1]}".format(["a", "b"])                # b          （索引访问）
```

你不能在一个字符串中混用自动编号（`{}`）和手动编号（`{0}`），这会引发 `ValueError`。

### 格式规格迷你语言

花括号中冒号之后的部分是格式规格（format spec）。
它控制宽度、对齐、填充、精度、分组以及类型代码。
同样的规格适用于 f-string、`str.format` 和 `format()`。

通用形式是 `[[fill]align][sign][#][0][width][grouping][.precision][type]`。

```python
f"{42:5}"          # '   42'    宽度 5，右对齐（数字的默认对齐方式）
f"{'hi':<5}|"      # 'hi   |'   左对齐（字符串的默认对齐方式）
f"{'hi':>5}|"      # '   hi|'   右对齐
f"{'hi':^5}|"      # ' hi  |'   居中
f"{42:*^7}"        # '**42***'  用 * 填充，居中
f"{42:05}"         # '00042'    用零填充到宽度 5
f"{3.14159:.2f}"   # '3.14'     定点数，2 位小数
f"{0.25:.0%}"      # '25%'      百分比
f"{1234567:,}"     # '1,234,567'  逗号分组
f"{1234567:_}"     # '1_234_567'  下划线分组
f"{255:x}"         # 'ff'       十六进制
f"{255:#x}"        # '0xff'     带前缀的十六进制
f"{5:b}"           # '101'      二进制
```

对于浮点数，`.2f` 四舍五入到两位小数，而 `.2g` 控制的则是有效数字位数。
冒号后的单独数字（没有类型）被视为最小字段宽度。

### 旧式 `%` 格式化

最古老的风格使用 `%` 运算符和 `printf` 风格的代码。
你仍然会在旧代码和 `logging` 模块的消息模板中遇到它。

```python
"%s is %d" % ("Ada", 36)     # 'Ada is 36'
"%.2f" % 3.14159             # '3.14'
"%05d" % 42                  # '00042'
```

单个非元组值可以直接使用（`"%s" % name`），但如果你的那一个值本身是元组，你必须把它包起来：`"%s" % (my_tuple,)`。
新代码优先使用 f-string；`%` 格式化主要用于旧代码维护，以及延迟格式化的 logging 调用。
