一个表达式可以在不需要任何语句的情况下在两个值之间做出选择。
这就是条件运算符（三元运算符），它接受三个操作数：一个条件、条件为真（true）时生成的值，以及条件为假（false）时生成的值。

```cpp
static int fee(int weight) {
    return weight > 20 ? 15 : 5;
}
```

`weight > 20` 是条件。
`?` 将其与两个候选值分隔开，而 `:` 则将这两个候选值彼此分隔，形式为 `condition ? whenTrue : whenFalse`。
整个结构是一个代表单个 `int` 的表达式，这就是为什么它可以直接跟在 `return` 后面或位于赋值语句的右侧。
只有被选中的那一侧会被求值，因此另一侧的值永远不会被计算。

两侧都必须是产生值的表达式而不是语句，因此它们内部不能包含分号，并且两侧的类型必须一致。
如果一侧是 `int`，另一侧是字符串字面量，运算符就无法确定单一的结果类型，文件将无法通过编译。
将此类表达式嵌套在另一个表达式内部是合法的，但这会使代码的阅读顺序变得难以推测，因此这里请保持单次选择即可。

`absoluteDifference(int left, int right)` 返回两个 `int` 值之间的距离，结果是一个非负数。
初始代码已经包含了条件 `left > right`，且两侧均为 `0`；请将每个 `0` 替换为该侧成立时正确的减法表达式。
两个相等的值会走 false 分支并依然得出 `0`；跨越零的一对值会计算两者的总距离，例如 -3 和 5 相距 8。
两个值都在 -10000 到 10000 之间，并且某组评分测试用例与另一组共享第一个值但结果不同，因此必须读取 `right`。
这里禁止使用 `if`，因此只能使用 `?` 来进行选择。

## 解答

```cpp
struct Solution {
    static int absoluteDifference(int left, int right) {
        // 每个分支使用各自对应的减法
        return left > right ? left - right : right - left;
    }
};
```
