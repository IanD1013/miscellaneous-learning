起始代码中的那一行 `return code - '0';` 对十个数字字符能够正确返回结果，但对其他任何字符也会同样“自信”地给出结果。
如果传给它一个大写字母的 code，它会返回 17，而调用者根本无法将其与真正的数字值区分开来。

卫语句（guard clause）是写在函数顶部的一个 `if`，用于识别函数无法处理的输入，并在主要逻辑开始前提前退出：

```cpp
static int half(int total) {
    if (total < 0) {
        return -1;
    }
    return total / 2;
}
```

该 `if` 内的 `return` 会立即退出函数：将值返回给调用者，并且在该执行路径上不会运行其下方的任何代码。
这种提前返回就是完整的拒绝处理，因此卫语句不需要用 `else` 包裹函数体的其余部分，主要逻辑也可以保持在最外层缩进，而无需因每个条件而陷入更深的一层。
两个职责单一的卫语句比一个冗长的条件语句可读性更好，因为每个卫语句都只因单一原因进行拒绝。

卫语句返回的内容必须能够被识别为拒绝。
这里使用 `-1` 作为哨兵值（sentinel），因为所有有效答案都在 `0` 到 `9` 之间，所以不会有任何真实结果与它冲突。
如果改为返回 `0`，则会在无形中破坏调用者的逻辑，因为 `0` 是字符 `'0'` 的正确答案。
用语言来描述该函数：它返回数字字符对应的值；对于任何非数字字符的 code，返回 `-1`。
这个文档中明确约定的失败返回值，正是第 3 章中除数为零却无值可返时所欠缺的。

### 该函数公开的约定

- `digitValue` 接收一个名为 `code` 的 `char` 并返回一个 `int`。
  测试会读取返回值，因此在函数内部打印没有任何用处。
- 对于 `'0'` 到 `'9'`，返回数字本身的值（`0` 到 `9`）。
  `'0'` 本身返回 `0`，绝不返回哨兵值。
- 对于其他任何 code，刚好小于 `'0'` 的字符、刚好大于 `'9'` 的字符、任何大小写字母、标点符号，都返回 `-1`。
- 仅使用 `if` 和 `return` 构建这两个卫语句，因此你的答案中必须出现 `if`。
  在代码编译前，`else`、`?` 以及数字字面量 `48` 都会被拒绝：请改用字符字面量 `'0'` 和 `'9'` 进行比较。

### 解答

```cpp
struct Solution {
    static int digitValue(char code) {
        // 在这一行之前拒绝所有不是十个数字字符的 code
        if (code < '0') {
            return -1;
        }
        if (code > '9') {
            return -1;
        }
        return code - '0';
    }
};
```
