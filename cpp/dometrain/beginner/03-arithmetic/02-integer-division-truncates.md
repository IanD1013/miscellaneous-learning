用一个 `int` 除以另一个 `int` 会返回一个 `int`，这在除法发生时强制做出了一个决定：`7 / 2` 的结果是 3，而 `19 / 20` 的结果是 0。
这里没有任何四舍五入。
整数除法会进行截断，即丢弃小数部分，只保留剩下的整数部分。

从这个角度来看，商回答了一个精确的问题：左边的值中可以容纳多少个完整的除数。
总数为 19 按每组 20 进行划分无法凑成任何一个完整组，因此 0 是准确的计数，而不是“差一点”。
被丢弃部分的大小是一个单独的问题，有着它自己的答案，而且仅凭商本身是无法恢复它的，因为 `7 / 2` 和 `6 / 2` 的结果都是 3。

### 要求

- 完成 `fullGroups(int total, int groupSize)`，它返回一个 `int`。
- 使用 `/` 运算符将 `total` 除以 `groupSize`（`total` 在左侧），并返回该计数值。
- `total` 的范围是 0 到 100000。
  所有评分测试的 `groupSize` 都为 1 或更大，因此组大小为 0 超出了该函数的考查范围，不需要你做任何检查。
- 答案中不应包含任何小数部分。
  此处不允许使用 `double`、`float` 以及如 `1.0` 和 `1.0f` 等小数字面量，因此计数必须直接来自于 `int` 除法本身，而不是来自最后才修剪截断的小数。

### 解答

```cpp
struct Solution {
    static int fullGroups(int total, int groupSize) {
        // 返回 total 中能容纳多少个完整的 groupSize 大小的组
        return total / groupSize;
    }
};
```
