在 C++ 中，有四个算术运算符负责数值计算：`+` 进行加法，`-` 进行减法，`*` 进行乘法，`/` 进行除法。
每个算术运算符都位于两个操作数之间并产生一个结果，而不会改变两边的操作数。
如果给它两个 `int` 类型的操作数，结果也是一个 `int`。

```cpp
int a = 12;
int b = 4;

int sum = a + b;         // 16
int difference = a - b;  // 8
int product = a * b;     // 48
int share = a / b;       // 3
```

操作数可以是字面量、变量或参数，因此 `a * b` 组合两个具名值的方式与 `12 * 4` 组合两个直接写出的数字完全相同。
计算结果本身并不会自动保存到任何地方。
如果单独写成一条语句，`a * b;` 计算出 48 后便会将其丢弃，`a` 仍然保持 12，`b` 仍然保持 4。
必须有某种方式来接收该值：初始化、赋值或 `return`。

这四个运算符中有两个对操作数的位置敏感。
`a + b` 和 `b + a` 结果相同，`a * b` 和 `b * a` 也是如此；但对于 `-`，左边的操作数是被减数，因此 `a - b` 为 8，而 `b - a` 为 -8。
`/` 的计算方向与之一致，即用左边的操作数除以右边的操作数。
当多个运算符出现在同一个表达式中时，`*` 和 `/` 的优先级高于 `+` 和 `-`，因此 `a + b * 2` 的计算结果为 20，若要强制改变运算顺序则需要使用圆括号。

填写 `totalOf` 函数，该函数按顺序接收 `groups`、`perGroup`、`extra` 和 `missing` 并返回一个 `int`。
将 `groups` 乘以 `perGroup`，再加上 `extra`，然后从中减去 `missing`。
请确保将 `missing` 放在 `-` 的右侧，因为如果两者颠倒位置，某个评分用例的符号就会反转。

测试比对的是返回的数值，因此打印输出并没有作用。
在某个测试用例中 `extra` 传入的值为 0，此时它不会产生影响。
`missing` 的值可能会大于前面的所有项之和，由此得出的负数总和也是正确的答案。
所有四个参数的值均在 -10000 到 10000 之间。

## 解答

```cpp
struct Solution {
    static int totalOf(int groups, int perGroup, int extra, int missing) {
        // 将四个数量合并为一个总数并返回
        return groups * perGroup + extra - missing;
    }
};
```
