`100 / 5 * 2` 的结果是 40，而不是 10。
同级别的运算符从左到右依次计算，因此先进行除法运算，乘法运算则基于除法的结果继续计算，而 `20 - 8 - 5` 也是先减去 8，然后再减去 5。

优先级是该规则的另一半，而且你已经接触过它：`*`、`/` 以及取余运算符比 `+` 和 `-` 结合得更紧密，这就是为什么无论代码行如何书写，`first + second * factor` 都会先乘后加。

```cpp
10 + 5 * 3     // 25：乘法先结合
(10 + 5) * 3   // 45：和先被分组
```

分组圆括号可以改变计算的顺序。
括号内的内容会首先被组合计算，并作为一个单独的值传递给外围的运算符。
它们绝不会改变运算符的行为，只会改变运算符接收的操作数，因此即使括号只是重申了默认的求值顺序也是无害的，反而可以使较长的代码行更易于阅读。

### 要求

- 完成 `scaledSumMinusOffset(int first, int second, int factor, int offset)`。
  将 `first` 与 `second` 相加，将该和乘以 `factor`，再从乘积中减去 `offset`，并将结果作为 `int` 返回。
- 使用一个返回表达式作答，并通过圆括号来控制运算顺序。
  此处不允许使用 `=` 字符，因此无法通过命名变量将公式拆分为多个步骤。
- 所有四个参数都是介于 -1000 到 1000 之间的 int。
  `first` 可能为负数，`second` 可能为 0，并且有一个评分测试调用使用了值为 1 的 `factor`，此时不加括号的运算顺序恰好与预期结果一致。

### 解答

```cpp
struct Solution {
    static int scaledSumMinusOffset(int first, int second, int factor, int offset) {
        // 用一个表达式返回整个公式
        return (first + second) * factor - offset;
    }
};
```
