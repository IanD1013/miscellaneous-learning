单引号包裹单个字符会构成字符字面量（character literal），而 `char` 就是用来保存它的类型：

```cpp
char grade = 'A';
```

引号决定了类型。
`'A'` 是单个字符，可以放入 `char` 中；而 `"A"` 是字符串字面量（string literal），这是另一种类型，编译器将其表示为 `const char *`，并在需要 `char` 的地方拒绝接受它。

`char` 也是一个占用一个字节的小整数，它保存的数值代表该字符的字符编码（character code）。
字母编码按字母表顺序排列，因此两个字符相减可以得出它们之间的步长距离，而在一个字符上加上一个距离则可以使它沿字母表移动：

```cpp
char upper = 'H';
char lower = upper + ('a' - 'A');
```

`'a' - 'A'` 是大小写之间的距离（此处为 32），此时 `lower` 中保存的就是 `h`。
反过来，同样的距离也可以将小写字母转换回其大写字母的编码。

因为 `char` 是一个数字，所以评分参数以数字形式给出：97 代表 a，122 代表 z。
预期答案则显示为单字符，例如 `A` 和 `Z`，原因类似：从声明返回 `char` 的函数中返回的值，在到达评分系统时表现为其对应的字符，而不是其数值编码。

编写 `upperFromLower`，使其返回 `letter` 的大写形式。
函数名说明了其取值范围：每个评分参数都是编码在 97 到 122 之间的小写字母，一次减法运算即可覆盖全部 26 个字母。
超出该范围的编码绝不会传入，函数也无需识别它们。

- 根据字符编码推导答案。
  这里有一条规则禁用了任何拼写形式的 `toupper`（无论前面是否带有 `std::`）。
- 你的代码中不能出现字面量 `32`。
  请将该距离表示为两个字符字面量的差值。

## 解答

```cpp
struct Solution {
    static char upperFromLower(char letter) {
        // 在此返回 letter 的大写形式
        return letter - ('a' - 'A');
    }
};
```
