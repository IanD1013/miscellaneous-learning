`double` 是用于保留小数点后部分的数据类型，而 `int` 无法做到这一点。
它的声明方式和所有类型一样，先写类型，后写名称。

```cpp
double half = 2.5;
double tenth = half * 0.2;
```

带有小数点的数字（例如 `2.5`、`0.2` 或 `4.0`）是小数字面量，其类型为 `double`。
如果将相同的数值写为 `1 / 4`，得到的结果则完全不同：斜杠两边都是 `int` 值，结果为 `0`，小数部分还没来得及存入 `double` 就已经丢失了。

### 返回的 double 是如何打印的

测试运行器在打印返回的 `double` 时会保留十五位有效数字，并且不显示末尾的零。
`16` 的四分之一是 `4.0`，因此打印出来显示为 `4`。
期望值没有包含小数点并不代表该测试用例需要一个 `int`。

`quarterOf(double value)` 返回一个 `double`，即其参数的四分之一。
在你的代码中写入 `0.25`，在返回的表达式中将 `value` 与其相乘，或者先将其存入你自己的 `double` 变量中。
本练习的一条规则禁止使用斜杠，因此不能用 `value / 4` 来代替字面量，你的代码中完全不能出现除法。
`16` 的四分之一是 `4`，`6` 是 `1.5`，`0` 是 `0`，`-3` 是 `-0.75`，`0.5` 是 `0.125`。
在整个过程中都要将小数部分保留在 `double` 中。
若将四分之一存入 `int`，`-3` 的结果会返回 `0`；若在缩放计算前将参数存入 `int`，`0.5` 就没有任何小数部分可供计算四分之一了。

### 解答

```cpp
struct Solution {
    static double quarterOf(double value) {
        // 将 value 乘以 0.25 并返回结果
        return value * 0.25;
    }
};
```
