变量是一块具名的存储空间，只需一条语句即可完成它的创建和赋值：

```cpp
int score = 0;
```

从左到右阅读这行代码。
`int` 是类型，它决定了该存储空间可以容纳的值的种类。
`score` 是变量名，在其所在代码块的后续部分中，每次提及该名称都会访问这同一块存储空间。
`=` 用于初始化该变量，这种形式称为复制初始化（copy initialization）：先计算其右侧的表达式，然后将结果复制到新变量中。
分号则用来结束该语句，就像结束你编写的任何其他语句一样。

这两个部分可以拆开，但这样可能会导致值丢失。
单独的 `int score;` 仍然是一个声明，因此变量名可以使用，但存储空间中尚未存入任何内容，读取它的行为是未定义的（undefined）：编程语言不保证会返回什么值，本评测引擎也是如此。
在创建变量的同一条语句中为其赋值，可以消除这种隐患。

你的评分函数是 `sumOfTwo(int first, int second)`，它返回一个 `int`。
声明一个该类型的变量，在同一条语句中使用 `=` 将 `first + second` 赋给它，并将其 `return`。
评测不会检查你选择的变量名，因此命名为 `total` 或 `answer` 都可以。

测试会读取函数返回的值。
本练习中禁用了 `std::cout`，因此调试打印并不是无害的，它会导致提交失败。
将运行四个测试用例：`7` 和 `5` 得到 `12`，两个零得到 `0`，`-9` 和 `9` 得到 `0`，以及 `-4` 和 `-6` 得到 `-10`。
一次加法即可涵盖所有四种情况，无需针对任何用例进行单独处理。

## 解答

```cpp
struct Solution {
    static int sumOfTwo(int first, int second) {
        int total = first + second;
        // 在返回前，total 已经保存了 first 和 second 的和
        return total;
    }
};
```
