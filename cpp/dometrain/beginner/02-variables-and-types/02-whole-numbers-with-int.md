`int` 用于存储没有小数部分的整数。
在此目标平台上，它占用四个字节，其取值范围为 -2147483648 到 2147483647。
C++ 还有其他整数类型，其大小在不同平台之间有所差异，因此本课程统一使用 `int`，并确保每个值都完全在该范围内。
直接写在代码中的数字，例如 `0`、`60` 或 `2000`，属于整数字面量：其值在编译时确定，且类型为 `int`。

一旦变量存在，修改它时无需重复声明类型：

```cpp
int count = 3;
count = count + 5;
```

第二行是一条赋值语句。
它的右侧根据 `count` 当时的值进行计算，计算结果替换旧值，因此从这里开始 `count` 的值为 `8`。
如果在第二行前面加上 `int`，就相当于在同一代码块中请求创建同名的第二个变量，编译器会将其报错为重新定义（redefinition）而非更新。

### 一个变量，两次更新

`counterAfter(int start, int firstChange, int secondChange)` 返回在依次将两次变动累加到计数器后，该计数器最终持有的 `int` 值。
从 `start` 开始声明一个 `int` 变量，将 `firstChange` 加到该变量上并将结果存回同一个变量中，以同样的方式加上 `secondChange`，然后将其返回。
请完整写出这两次更新操作：此处禁用了 `+=`。
这些语句均围绕 `=` 构建，本练习要求在你的代码中显式使用它；起始代码中没有任何声明，因此在这一规则上没有提供预设代码。
评分系统比对的是返回的最终数字，因此两条赋值语句是本节课要练习的形式，而不是测试可以直接检查到的内容；直接在声明中写入计算好的最终总和等于跳过了练习，而不是解决了练习。

`[10, 5, 3]` 返回 `18`。
`[9, -4, -5]` 返回 `0`。
`[3, -10, 2]` 返回 `-5`，因为累计总和可以为负数。
`[8, 0, -3]` 返回 `5`，因为加 `0` 不需要特殊处理。
`[900000000, 100000000, -500000000]` 返回 `500000000`，且该用例的每一步都在上述取值范围内。

### 解答

```cpp
struct Solution {
    static int counterAfter(int start, int firstChange, int secondChange) {
        // 从 start 声明一个 int 计数器，依次应用两次变动，然后返回
        int counter = start;
        counter = counter + firstChange;
        counter = counter + secondChange;
        return counter;
    }
};
```
