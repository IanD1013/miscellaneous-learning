可以通过位置从字符串中取出一个字符，写法为 `s[i]`：在方括号中填入你想要的位置。

```cpp
std::string s = "hey";

char first = s[0];
char last = s[s.size() - 1];
```

`first` 保存 `'h'`，`last` 保存 `'y'`。
位置从 0 开始，因此首个字符位于 0，末尾字符位于 `size() - 1`（比总数少 1）。
返回的值是一个 `char`（单个字符），而不是单字符字符串。

没有任何机制会替你检查位置。
只有当 `i >= 0` 和 `i < s.size()` 同时满足时，索引才处于有效范围内，而引擎在读取之前不会检查这两项。
超出该范围的读取不会可靠地发出警告：它可能会返回一个看似合理但实际上从未存在于文本中的值，且没有任何提示信息。
本练习不会针对此类读取产生的结果进行评分。
`.at()` 也不能作为替代方案：如果拒绝某个位置，它会以退出代码 134 终止整个用例，调用方无法对此做任何处理。
请先验证索引，然后再读取：访问文本的唯一路径应当是已经通过比较确认索引有效的那条路径。

直接将 `int` 与 `size()` 比较会掩盖这种验证，而不是明确表达它。
由于字符数量是无符号类型（unsigned），`int` 会被转换以匹配它，导致 `-1` 变成一个巨大的数值并恰巧被拒绝。
使用 `static_cast<int>(text.size())` 可以让两边都保持为 `int`：`-1 >= 5` 显然为假，这样负数索引就成了一个你有意处理的情况。

### 要求

- `characterAt(const std::string &text, int index)` 返回一个 `char`，测试用例会读取该返回字符。
- 对于文本中实际存在的位置，返回存储在该处的字符。
  在 `"abcde"` 中，索引 0 为 `'a'`，索引 4 为 `'e'`。
- 对于小于 0、等于 `text.size()` 或大于该值的索引，返回 `'?'`。
  空文本完全没有可用的位置，因此访问它的任何索引都会返回 `'?'`。
  自身包含问号的文本可能会从其实际存在的位置返回 `'?'`，因此 `'?'` 是一个调用方必须明确知道其文本永远不会产生的标记。
- 在与大小进行上限比较时将其转换为 `int`，以便在你的答案中出现 `static_cast<int>`；并对负数端单独与 0 比较，此处写为 `index < 0`。

### 解答

```cpp
#include <string>

struct Solution {
    static char characterAt(const std::string &text, int index) {
        // 先确认索引在有效范围内再读取，否则返回 '?'
        if (index < 0 || index >= static_cast<int>(text.size())) {
            return '?';
        }
        return text[index];
    }
};
```
