C++ 程序通过名为 `std::cout` 的流向控制台发送文本，而插入运算符 `<<` 则将值推入该流中：

```cpp
#include <iostream>

std::cout << "text";
```

该语句中的每个部分都承担一项工作。
`std::cout` 指定了控制台输出流。
`<<` 将其右侧的内容发送到其左侧的流中。
`"text"` 是一个字符串字面量：即双引号之间的字符，会按原样打印输出，包括空格。
分号用于结束语句，而不是视觉上的换行。

`std::cout` 是一个名称，而不是一个函数，因此 `std::cout("text")` 会要求编译器调用一个不可调用的对象，编译器会报错指出调用错误，而不是进行打印。
前面的 `std::` 是名称的一部分，表示它属于标准库。
此处的检查会读取你的文件以查找完全相同的拼写，因此无论打印出的行看起来多么正确，仅使用 `cout` 都会被拒绝。

该名称是通过 `#include <iostream>` 引入的。
这一行是一个指令而不是语句：在编译之前，编译器会将 `<iostream>` 头文件的内容粘贴到文件中，`std::cout` 的声明也会随之引入。
在到达编译器之前，删除它就会被拦截拒绝。
作为指令，它不需要分号。

起始代码中已经包含了 `printMessage`，即本练习运行的评分函数。
它被写为 `static` 是因为该引擎只能调用自由函数或静态函数。
你的代码应写在它的大括号 `{` 和 `}` 之间，大括号之外的所有内容都保持原样。
程序的 `main` 来自运行器，规则会阻止添加第二个 `main`，而不是由编译器报错。

打印输出 `Output from a C++ program` 这一行内容，不要包含其他任何内容。
三个测试用例会以递增的严格程度来比对这一行。
第一个用例会忽略大小写和空格，仅要求单词顺序正确；第二个用例会严格检查大小写；第三个用例则进行逐字符比对，因此哪一个用例未通过会提示你需要排查哪类差异。
全部通过这三个用例意味着大小写、单个空格以及没有多余的尾随空格都是正确的。
在比对之前，末尾的换行符会被去除，因此在此处行尾换行是可选的。

## 解答

```cpp
#include <iostream>

struct Solution {
    static void printMessage() {
        // 在此输出要求的那一行
        std::cout << "Output from a C++ program";
    }
};
```
