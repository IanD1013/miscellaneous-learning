标签和数字相继推入流中时，它们之间不会有任何分隔内容。
`std::cout << "Total:" << 7;` 会在控制台上输出 `Total:7`，因为 `<<` 会原样输出每一部分：各部分之间既不会自动添加空格，也不会添加逗号或任何分隔符。

因此，空格需要由你自己来写，并且它包含在带有标签的字面量中。
在一个传入名为 `score` 的数字的函数中，链式输出如下：

```cpp
std::cout << "Score: " << score << "\n";
```

标签字面量在闭合引号前以一个空格结尾，正是这个空格让数字没有紧贴着冒号。
数字本身通过同一个 `<<` 进入同一输出链，流在输出时会将其转换为十进制数字（包含负号）。
无需转换为文本，因此一行带有标签和值的输出可以随意混合带引号的文本与数字。

`printTotal` 接收一个名为 `total` 的数字。
请在单行中将其输出在固定标签 `"Total: "` 之后，使用参数名通过 `<< total` 插入，以便数字来自变量的值，而不是字面量中输入的固定内容。
初始代码中的 `#include <iostream>` 保持原样，完整的输出行通过 `std::cout` 发出，文件中既不需要 `main` 也不需要 `to_string`，因为流本身就会把数字转换为对应数位。
书写流名称时请带上前缀 `std::`：判定规则会在文件中搜索 `std::cout`，单独使用 `cout` 将无法匹配。

测试传入的每个值对应的输出行如下所示：

- `7` 输出 `Total: 7`
- `42` 输出 `Total: 42`，冒号后面的空格来自标签而不是数字
- `0` 输出 `Total: 0`，单个数位，既非空白也不是 `00`
- `-5` 输出 `Total: -5`，符号作为数字的一部分输出
- `1000000` 输出 `Total: 1000000`，不带分组分隔符

## 解答

```cpp
#include <iostream>

struct Solution {
    static void printTotal(int total) {
        // 在同一行输出标签和值
        std::cout << "Total: " << total << "\n";
    }
};
```
