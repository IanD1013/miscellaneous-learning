转义序列是由一个反斜杠后跟另一个字符组成的，编译器会将这对字符作为单个字符存储在文本中。
本练习所需的三个字符中，有两个无法直接输入到字面量中并表示它们自身。
第三个虽然可以，但仍然不应该这样做。

直接输入到字面量中的双引号会提前结束该字面量。
写成 `\"` 时，反斜杠将引号标记为数据，字面量则会继续：

```cpp
std::cout << "she said \"stop\"";
```

这会输出 `she said "stop"`，两个内部的引号都可见，且都不会闭合字面量。
没有任何反斜杠输出到控制台：每个反斜杠都用于标记其后面的引号。

制表符（tab）是两种方式皆可的字符。
在引号之间直接输入它是合法的，并且确实包含一个制表符，但在屏幕上它与空格无法区分，而且许多编辑器会在你输入时将其替换为空格。
写成 `\t` 时，它就是一个在你的编辑器以及任何其他人的编辑器中都保持为制表符的单个字符：

```cpp
std::cout << "one\ttwo";
```

控制台在那里显示一段间隙，且该间隙不是空格：一连串空格是一个不同的字符串，无论两者看起来多么相似，精确比较都会判定为不匹配。

因为反斜杠总是与其后面的字符结合，表示其自身的反斜杠需要写两次，即 `\\`：

```cpp
std::cout << "C:\\temp";
```

这会输出 `C:\temp`。
如果只有一个反斜杠，`"C:\temp"` 中原来是 `t` 的地方就会包含一个制表符，而 `temp` 会悄悄失去它的首字母。

在 `printEscapedLine` 中按顺序输出包含以下部分的一行内容：一个双引号、单词 `quoted`、一个双引号、一个制表符，然后是 `back\slash`（在 `back` 和 `slash` 之间有一个反斜杠）。
其余部分遵循三条规则：

- 禁止使用 `static_cast`，因此引号和反斜杠必须来自转义字符 `\"` 和 `\\`，而不是数值转义。
- 保留 `#include <iostream>`，并且该行必须通过完整拼写的 `std::cout` 配合 `<<` 输出，因为单纯的 `cout` 会导致该文本未包含在文件中。
- `main` 由运行器保留，因此此处禁止使用该标识符。

只有最严格的测试用例才能区分制表符与空格，因此三个用例中单个未通过（红色）的用例通常指向分隔符，而不是该行的其余部分。

## 解答

```cpp
#include <iostream>

struct Solution {
    static void printEscapedLine() {
        // 在此构建要求的那一行，包含转义序列
        std::cout << "\"quoted\"\tback\\slash";
    }
};
```
