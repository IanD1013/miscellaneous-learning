在输出中换行意味着在文本中放入一个换行符，而换行符是不能直接在引号之间键入的字符之一。
在字面量内部，它写作 `\n`。
这里的反斜杠是一个转义符：它改变了其后字符的含义，因此编译器会将 `\n` 存储为一个字符（即换行符），而不是反斜杠后跟一个 `n`。

```cpp
std::cout << "first\nsecond";
```

该语句会打印 `first`，将控制台光标移至下一行的开头，并在那里打印 `second`。
任何地方都不会显示反斜杠：在构建字面量时它已被消耗。

另一个特点是，`<<` 在插入内容后会返回流本身，从而支持链式插入：在一条语句中连接多个片段，从左到右处理，按编写的顺序打印，并用一个分号结束整条链，而不是在每个片段后都加分号。

```cpp
std::cout << "one" << "\n" << "two\n";
```

`<<` 本身不会将任何内容移到新行。
以这种方式连接的片段会并排排列，直到转义符指示换行为止；而转义符所在的位置决定了它在哪里换行：在字面量末尾它会结束该字面量所在的行，在开头则会结束前一行。

### 要求

- 在 `printThreeLines` 中依次打印 `Line one`、`Line two` 和 `Line three`。
  本节教学的形式是单条链式语句；评分系统仅检查捕获的文本。
- 在字面量中使用 `\n` 来构建两次换行，使用 `<<` 通过 `std::cout` 输出各个片段，并保留初始代码中的 `#include <iostream>`。
  请完整书写流名称，因为检查规则会在文件中搜索 `std::cout`，单独写 `cout` 将无法匹配该文本。
- 两次换行都会在所有严格级别下进行评分，因为三种比对方式都不会将两行合并为一行。
  漏掉 `\n` 会导致两个短语连在一起，这会被所有测试用例捕获；而在短语内部多留一个空格，则只有最严格的测试用例会报错。
- 在 `Line three` 后面换行不会产生任何影响，因为在比对之前会去除两端末尾的换行符。
- 禁止以任何形式使用 `endl`（包括 `std::endl`），因为此处的换行应当包含在字面量内部，且 `main` 函数由运行器负责定义。

### 解答

```cpp
#include <iostream>

struct Solution {
    static void printThreeLines() {
        // 在此用一条语句输出三行
        std::cout << "Line one" << "\n" << "Line two" << "\n" << "Line three";
    }
};
```
