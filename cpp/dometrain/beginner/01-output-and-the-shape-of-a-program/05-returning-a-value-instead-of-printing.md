到目前为止评分的所有内容都是打印到控制台并从中读取的。
而 `buildMessage` 则将其答案返回给调用它的代码，形式很简短：

```cpp
static std::string greeting() {
    return "hello";
}
```

`std::string` 写在函数名前面，是返回类型：它声明了函数返回什么类型的值。
本章前面用于打印的函数被声明为 `void`，即不返回任何内容的返回类型。
`std::string` 是标准库类型，用于将任意长度的文本保存为值，这使得函数可以像返回数字一样返回文本。

`return` 在一条语句中完成两项工作。
它将值返回给调用者（在此过程中不打印任何内容），并在原地结束函数，因此同一代码块中其下方的语句都不会运行。
因此，依次排列的两个 `return` 语句不能产生两个答案：第一个 `return` 就会退出函数。
返回值也必须符合声明的类型：上面的 `"hello"` 是一个字符串字面量，从声明为 `std::string` 的函数中返回它，会向调用者传递一个包含这些字符的字符串值。

该类型需要引入头文件。
初始代码的顶部包含 `#include <string>`，因为 `std::string` 是在 `<string>` 中声明的，而不是在前面练习使用的控制台头文件中声明的。
请保留该行。

### 评分器读取的内容

评分方式从这里开始改变，并且大部分后续练习都保持这种方式：评分器会检查返回值，并忽略函数打印的任何内容，因此即使控制台看起来完美无缺，打印也不是正确答案。
返回值不会被修剪（trim），因此多出的换行符或多余的空格都会被视作实质性的差异，而不仅仅是格式习惯。

这里的比较严格程度也是不可调整的。
返回值会进行逐字符比较，因此这三个测试用例会把同一种比较运行三次：它们会一起通过（变绿）或一起失败（变红），不会像之前部分通过的测试集那样单独区分某个大写字母或空格。

从 `buildMessage` 中精确返回 `Returned instead of printed`，大小写和单个空格需与显示完全一致，两端不得有多余内容。
替换初始代码中的 `return "";`。
已声明的 `std::string` 保持不变，`main` 属于测试运行器。
