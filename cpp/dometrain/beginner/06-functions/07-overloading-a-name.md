只要参数列表不同，两个函数就可以共享同一个名称。
以这种方式编写的一组函数构成了一个重载集（overload set）：

```cpp
static int total(int a, int b) {
    return a + b;
}

static int total(int a, int b, int c) {
    return total(a, b) + c;
}
```

`total(2, 3)` 会运行第一个函数体，而 `total(2, 3, 4)` 会运行第二个。
区分这两个函数的是它们各自接收的参数数量；参数类型的差异同样也能区分它们。
返回类型不参与重载比较，因此在第一个版本旁边放置 `static double total(int a, int b)` 会导致重复定义错误，而不是构成第三个重载。

在它们之间进行选择的过程称为重载决议（overload resolution），编译器会在每次调用时执行该过程。
它会收集所有带有该名称的函数，保留参数列表能够接收调用处所传实参的函数，并选取完全匹配的那一个。
两个实参只匹配第一个版本，三个实参只匹配第二个版本。
如果调用不匹配任何一个版本（例如 `total(7)`），或者有两个版本匹配程度相同，都会导致编译错误。
所有这些都在编译文件时确定，因此调用者随后对结果的处理不会产生任何影响。
三参数函数体内部的 `total(a, b)` 会经历相同的步骤，并匹配到双参数版本。

在这里，默认参数无法替代额外的版本。
写入参数列表的值不能引用另一个参数，并且每个实参的范围都在 -1000 到 1000 之间，因此任何固定的第三个值都可能恰好是最小值而成为答案。

起始代码包含两个函数头，且两者都要保留：`static int minOf(int a, int b)` 返回其两个实参中的较小值，而 `static int minOf(int a, int b, int c)` 返回其三个实参中的最小值。
运行器自带的 `main` 会调用这两个函数。
该名称不接受重复定义，因此在这里编写重复定义会导致构建失败。
使用 `<` 进行比较并返回较小的值，并让三参数函数体调用双参数版本，而不是重复进行比较。
出现相同值时返回该共享值，因此 `minOf(6, 6)` 为 6，`minOf(-7, 12, -7)` 为 -7。
`minOf(9, 4)` 为 4，`minOf(8, 5, 3)` 为 3，`minOf(3, 8, 5)` 也为 3，而 `minOf(-1000, -4, -999)` 为 -1000，所有输入均需被正常接受。

## 解答

```cpp
struct Solution {
    static int minOf(int a, int b) {
        // 返回两个值中较小的那个，相等时返回该共享值
        if (b < a) {
            return b;
        }
        return a;
    }

    static int minOf(int a, int b, int c) {
        // 复用两参数版本，而不是把比较再写一遍
        return minOf(minOf(a, b), c);
    }
};
```
