`for` 头部将三个子句整合到一行中，并用分号隔开：

```cpp
for (int i = 0; i < 3; i++) {
    std::cout << i;
}
```

这段代码会打印 `012`。
初始化部分 `int i = 0` 最先执行且仅执行一次，用于声明计数器。
条件 `i < 3` 会在每次循环迭代前进行检查，这与 `while` 头部执行的测试相同。
更新部分 `i++` 会在循环体完成一次迭代后执行，它会使计数器加 1，因此下一次迭代读取到的值会比当前迭代多 1。
第 3.6 课中介绍了该步骤的两种写法：`i++` 和 `++i`，无论哪种写法，更新子句都会使计数器递增 1。
因此，每一轮循环的顺序都是：测试、循环体、更新，然后进行下一次测试。
这就是为什么循环体在第一次迭代时看到的计数器为 0，而永远不会看到它为 3。

### 计数器属于循环

在初始化部分声明的计数器会在头部执行时创建，并在循环结束时销毁。
放在闭合花括号后面的代码无法读取 `i`，因为该名称在外部已不复存在。
任何生命周期需要长于循环的变量（例如累加总和），都必须声明在头部上方。

计数的两端都应计入总和：`sumOfSquares(4)` 会将 1、4、9 和 16 相加得到 30，因此 `sumOfSquares(int n)` 涵盖从 1 到 `n` 的每个计数器值，并将每个值平方后累加。
使用一个 `for` 头部来控制它，其初始化部分声明计数器并从 1 开始，以 `i <= n` 作为条件以确保最后一个值也能参与迭代。
不要在其他地方修改步长：在花括号之间再写一个 `i++` 会使计数器每次迭代递增两次，从而跳过一半的值。
`n` 可以为 0 或负数，两者都应返回 0，因为条件在第一次测试时就会失败。
`n` 最大为 1000。
将每个平方数累加到头部上方声明的总和变量中，并在循环结束后返回该总和。

### 解答

```cpp
struct Solution {
    static int sumOfSquares(int n) {
        // 把从 1 到 n（包含 n）的每个计数器值的平方累加起来
        int total = 0;
        for (int i = 1; i <= n; i++) {
            total += i * i;
        }
        return total;
    }
};
```
