`do` 会先执行循环体，然后再检查条件：

```cpp
int n = 0;
do {
    n += 1;
} while (n < 0);
```

`n` 最终的值为 1。
进入循环体不需要进行任何条件判断，因此循环体总是至少运行一次，只有在运行之后，末尾的 `while (n < 0)` 才会决定是否进行下一次循环。
结构上有两个细节需要注意：条件位于闭合大括号的下方，且语句以闭括号后面的分号 `);` 结尾。
如果没有这个分号，文件将无法编译。
如果是相同的代码使用 `while` 循环，则会先检查 `n < 0`，发现为 false，从而使 `n` 保持为 0。

减半操作将终结你即将编写的循环。
正如第 3.2 课所示，整数除法会截断小数部分，因此 `value /= 2` 会将 8 变为 4，然后变为 2，再变为 1，最后变为 0：`1 / 2` 的结果是 0 而不是分数，这就是为什么正值在递减过程中不会卡住的原因。
请记得将减半后的结果赋值回去，因为单独的 `value / 2` 只会计算出一个数字并将其丢弃，导致条件永远读取到相同的值，最终因 20 秒 watchdog 超时而终止运行。

编写 `halvingSteps(int start)`。
小于 0 的 start 超出了该计数的定义范围，因此在循环前面放置一个守卫语句（guard）返回 -1，且不计入任何循环次数。
通过守卫检查后，每次减半计作一次循环并返回该计数值，因此 `halvingSteps(8)` 返回 4，`halvingSteps(1)` 返回 1（即把 1 变成 0 的那一次循环）。
`start` 为 0 时同样返回 1，而不是 0：虽然没有可以继续减半的了，但在读取末尾的测试条件时循环体已经运行了一次，并且该次循环与其他循环一样计入总数。
允许的最大 `start` 为 1000000，这需要 20 次循环。
使用 `do` 来构建循环，以便在进行任何判断之前先执行第一次循环。

## 解答

```cpp
struct Solution {
    static int halvingSteps(int start) {
        // 负数起始值直接拒绝，否则统计把值减半到 0 所需的循环次数
        if (start < 0) {
            return -1;
        }
        int value = start;
        int passes = 0;
        do {
            value /= 2;
            passes += 1;
        } while (value > 0);
        return passes;
    }
};
```
