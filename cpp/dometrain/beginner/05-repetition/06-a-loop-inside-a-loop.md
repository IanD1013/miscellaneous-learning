循环体内部可以包含另一个循环，并且外层循环每执行一次，内层循环都会从头开始完整运行：

```cpp
for (int i = 1; i <= 2; ++i) {
    for (int j = 1; j <= 3; ++j) {
        std::cout << i << j << "\n";
    }
}
```

程序会按顺序输出 6 行：11、12、13、21、22、23。

### 哪个计数器会重新开始

`for (int i` 是外层循环的头部，而 `for (int j` 是内层循环的头部。
外层循环每次迭代都会再次到达内层循环的头部，因此其初始化子句 `int j = 1` 也会再次运行，`j` 会在 `i` 为 2 时像在 `i` 为 1 时一样依次计数 1、2、3。
`i` 不会重新开始：它的初始化仅在第一次迭代之前运行一次，且只有在内层循环完整运行完毕后才会执行 `++i`。
每个计数器都向着固定不变的上限每次递增 1，因此内层循环会分别到达终点 3 次，外层循环在经历 2 次迭代后结束，而最内层的循环体一共运行了 6 次。

请补全 `sumOfProducts(int rows, int cols)` 函数，该函数返回每个行号与每个列号相乘的总和，行号为 1 到 `rows`，列号为 1 到 `cols`。
嵌套循环结构以及其上方的 `total` 已经为你写好；你只需要补充一条语句，在内层循环体每次执行时将 `i * j` 累加到 `total` 中。
`sumOfProducts(3, 3)` 的结果应为 36，`sumOfProducts(3, 4)` 的结果应为 60。
请将 `total` 保留在初始代码放置的位置（即外层循环上方），否则外层循环的每次迭代都会丢弃之前已计算的行数据。
如果 `rows` 或 `cols` 小于等于 0，则无需额外的防护判断：该循环头部的条件在第一次测试时就会失败，其循环体一次都不会运行，直接返回 `total` 中的初始值 0，这也正是 `sumOfProducts(3, -2)` 所期望的结果。

### 解答

```cpp
struct Solution {
    static int sumOfProducts(int rows, int cols) {
        int total = 0;
        for (int i = 1; i <= rows; ++i) {
            for (int j = 1; j <= cols; ++j) {
                // 把行号乘以列号的积累加到 total 中
                total += i * j;
            }
        }
        return total;
    }
};
```
