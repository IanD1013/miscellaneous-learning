只要条件为真，`while` 循环就会重复执行一段代码。
下面这个循环会将 `n` 减半，直到它小于 2：

```lua
local n = 40
while n >= 2 do
  n = n // 2
  print(n)
end
```

控制台会逐行显示 20、10、5、2 和 1。

条件位于 `while` 和 `do` 之间，这里是 `n >= 2`。
`do` 和 `end` 之间的代码行为循环体。
Lua 会在每次遍历之前检查条件，包括第一次：当条件为真时执行循环体；当条件为假时循环结束，程序继续执行 `end` 之后的代码。
在此例中，第五次遍历将 2 变为 1，接下来的检查发现 `1 >= 2` 为假，循环停止。
如果 `n` 从 1 开始，则不会打印任何内容，因为第一次检查就已经失败，循环体执行零次。

循环体内必须有某些操作促使条件趋于假，在这里 `n = n // 2` 通过在每次遍历中使 `n` 变小来实现这一点。
如果没有该行，`n` 将保持为 40，循环永远不会结束。
运行会在 5 秒后停止此类循环，并报错指出对应的行号。

数值型 `for` 循环在开始前就可以根据其初始值、终止值和步长知道遍历的次数。
而 while 循环不需要预设次数：它会一直遍历，直到其条件不满足为止。

### 计算 3n + 1 规则的步数

编写 `collatz_steps(n)`，其中 `n` 是至少为 1 的整数。
3n + 1 规则的一步操作将偶数 `n` 变为 `n // 2`，将奇数 `n` 变为 `3 * n + 1`。
不断执行这些步奏，直到 `n` 变为 1，并返回所经历的步数。
数字 1 不需要任何步数，因此 `collatz_steps(1)` 返回 0。
该规则生成的数字序列被称为考拉兹序列（Collatz sequence），函数名由此而来。

没有人能预先给出该步数：8 经过 3 步到达 1，但比它小 1 的 7 却需要 16 步。
因此，当 `n` 不为 1 时进行循环，每次遍历执行一步，并使用带有 `else` 的 `if` 来选择应用的规则。
`n % 2` 是除以 2 后的余数，因此对于偶数 `n` 它为 0。
使用一个局部变量进行计数：在循环前将其设为 0，在每次遍历结束时加 1，并在循环后将其返回。

### 解答

```lua
function collatz_steps(n)
  local steps = 0
  while n ~= 1 do
    if n % 2 == 0 then
      n = n // 2
    else
      n = 3 * n + 1
    end
    steps = steps + 1
  end
  return steps
end
```
