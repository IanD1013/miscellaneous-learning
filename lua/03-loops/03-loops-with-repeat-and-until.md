`while` 循环会在第一次执行前测试其条件，因此它可能完全不运行循环体就直接结束。
下面这个循环在每次执行时通过整除（`345 // 10` 结果为 `34`）去掉 `n` 的最后一位数字。
从 0 开始时，它什么都不会打印：

```lua
local n = 0
while n > 0 do
  n = n // 10
  print(n)
end
```

`0 > 0` 为 false，因此循环体被跳过。
Lua 还有另一种在执行后进行测试的循环，使用 `repeat` 和 `until` 编写。
同样逻辑的循环采用这种形式时会打印一次 `0`：

```lua
local n = 0
repeat
  n = n // 10
  print(n)
until n == 0
```

`repeat` 开始循环，其后的代码行为循环体。
`until` 加上一个条件用于结束循环，因此不需要 `do` 也不需要 `end`。
每次循环都会先执行循环体，然后测试条件，并且在条件首次为 true 时停止循环。
这与 `while` 正好相反，`while` 会在条件为 true 时一直运行。
由于测试在循环体之后进行，所以 `repeat ... until` 循环总是会至少运行一次循环体。

将第二个循环粘贴在你的函数下方，并将 `n` 设置为 `345`。
在点击 Run 之前，预测一下它打印的最后一个数字是 `3` 还是 `0`。

编写 `count_digits(n)`，其中 `n` 是一个非负整数。
返回 `n` 正常书写时的位数，例如 `count_digits(12345)` 返回 `5`。
零写作单个数字，因此 `count_digits(0)` 返回 `1`，而 `repeat ... until` 循环无需特殊处理就能自然实现这一点：循环体运行一次并计入该数字，`0 // 10` 仍然是 `0`，然后循环结束。

每次循环都会去掉一位数字，因此统计循环次数就等于统计位数。
维护一个从 0 开始的局部计数变量，在每次循环时给它加 1，并在循环结束后返回它。
使用 `//` 而不是 `/` 去掉数字。
`/` 总是返回浮点数，因此 `12 / 10` 是 `1.2` 而不是 `1`。

### 解答

```lua
function count_digits(n)
  local count = 0
  repeat
    n = n // 10
    count = count + 1
  until n == 0
  return count
end
```
