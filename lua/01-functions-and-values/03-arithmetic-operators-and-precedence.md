`+` 表示加，`-` 表示减，`*` 表示乘，`/` 表示除。
像这样的符号被称为运算符：每一个运算符都会对其两边的数字进行运算并产生一个新数字。
写在单个数字前面的 `-` 会将其变为负数，例如 `-6`。
将以下几行代码放入编辑器中，点击运行，控制台会显示：

```lua
print(2 + 6 / 2)
print((2 + 6) / 2)
print(6 / 2)
```

```text
5.0
4.0
3.0
```

从左到右阅读 `2 + 6 / 2` 会得到 4，但 Lua 给出的结果是 5.0。
`*` 和 `/` 的优先级高于 `+` 和 `-`，这意味着 Lua 会先计算它们：它先用 6 除以 2，然后再加上 2。
圆括号可以改变这种顺序。
Lua 会优先计算括号内的内容，因此第二行先计算 2 加 6，然后再用 8 除以 2。

所有三个结果都以 `.0` 结尾，因为 Lua 有两种数字类型。
整数（integer）是像 `4` 这样的整数，而浮点数（float）是可以包含小数部分的数字，例如 `3.5`。
`/` 总是会产生浮点数，即使两个数字都是整数且可以整除，因此 `6 / 2` 会得到 `3.0`。
`3.0` 和 `3` 的数值大小相同；`.0` 只是表示该数字是一个浮点数。

### 你的任务

编写 `average(a, b)` 的函数体，使其返回 `a` 和 `b` 的平均值：即两者的和除以 2。
3 和 4 的平均值是 3.5，2 和 4 的平均值是 3，-6 和 2 的平均值是 -2。

### 解答

```lua
function average(a, b)
  return (a + b) / 2
end
```
