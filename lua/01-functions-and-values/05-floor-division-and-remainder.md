Lua 提供了两个运算符，用于将除法拆分为整数部分和余数部分。
`//` 是整除（向下取整除法）：它执行除法并将结果向下舍入为整数。
`%` 计算余数，即整除后剩余的部分。
两者都放在两个数字之间，就像 `+` 和 `*` 一样：

```lua
print(7 // 2)
print(7 % 2)
print(7 / 2)
print(6 / 2)
```

```text
3
1
3.5
3.0
```

7 里面可以容纳 3 个 2 还剩下 1，因此 `7 // 2` 是 `3`，而 `7 % 2` 是 `1`。
当两个数都是整数时，`//` 和 `%` 也会返回整数。
在算术运算中，`%` 不是百分号：在两个数字之间时，它始终表示求余。

即使两个数都是整数，`/` 也会保留小数部分：`7 / 2` 是 `3.5`。
它总是返回浮点数，因此 `6 / 2` 是浮点数 `3.0`，而在通过 `..` 连接到字符串中时会显示为 `3.0`，相比之下整数 `3` 连接时则为 `3`。

将分钟转换为小时也是同样的拆分方式，即除以 60。
`125 // 60` 为 `2`，表示 125 分钟中的完整小时数；而 `125 % 60` 为 `5`，表示这两个小时之后剩余的分钟数。
`125 / 60` 是一个浮点数，连接到字符串中会显示为 `2.0833333333333`，这对于表示小时数毫无用处。

### 你的任务

编写 `format_minutes(total)` 的函数体，其中 `total` 是一个介于 0 到 1440 之间的分钟整数。
返回由完整小时数、字母 `h`、一个空格、剩余分钟数和字母 `m` 组成的单个字符串：`format_minutes(125)` 返回 `2h 5m`，`format_minutes(60)` 返回 `1h 0m`，`format_minutes(59)` 返回 `0h 59m`。
将小时和分钟分别保存在两个 `local` 变量中，可以使 `return` 那一行更容易阅读。

### 解答

```lua
function format_minutes(total)
  local hours = total // 60
  local minutes = total % 60
  return hours .. "h " .. minutes .. "m"
end
```
