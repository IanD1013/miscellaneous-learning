函数通过参数获取输入，这些参数是写在函数定义括号中的名称。
这里的 `greet` 有一个参数 `name`：

```lua
function greet(name)
  return "Hello, " .. name .. "!"
end
```

调用 `greet` 时会在其括号中传入一个值，这个值就是实参（argument）。
由于定义中有 `(name)`，所以在调用运行时，`name` 会持有该实参。
在 `greet("Ada")` 中，实参是 `"Ada"`，因此 `name` 保存的是 `"Ada"`，并且 `greet` 返回 `Hello, Ada!`。
调用 `greet("Lua")` 时，相同的定义会返回 `Hello, Lua!`。
单词 `name` 对 Lua 来说并没有什么特殊含义。
它只是函数体用来指代该实参的名称，因此在括号和 `return` 行中将其重命名为 `who`，效果完全相同。

`..` 会将左侧的字符串与右侧的字符串拼接成一个新字符串，中间不会添加任何内容：`"ab" .. "cd"` 会得到 `abcd`。
以这种方式拼接字符串称为拼接（concatenation）。
上面的 `return` 行两次使用了 `..` 来拼接三部分内容。
问候语所需的任何空格或标点符号都必须放在引号内，这就是为什么 `"Hello, "` 以空格结尾的原因。
那么 `greet("")` 会返回什么呢？
一旦你的函数正常工作，`print(greet(""))` 就会在控制台中显示答案。

`+` 不能拼接文本。
它是用来给数字做加法的，如果用在非数字文本上（例如 `"Hello, "`），则会报错。

### 你的任务

编写 `greet` 的函数体，使其无论传入什么名字作为调用参数，都返回 `Hello,`，后跟一个空格、该名字以及 `!`。
名字可以包含空格，也可以为空。

### 解答

```lua
function greet(name)
  return "Hello, " .. name .. "!"
end
```
