### 暂存起来：stash push 和 pop

你正在 `app.js` 中构思编写代码，突然来了一件紧急任务。
你既不想提交只完成了一半的想法，又无法在有未提交修改的工作区中工作。
那就把它暂存起来吧。

1. `git stash push -m "half-finished idea"`：修改会被移入暂存区，工作区立刻恢复干净。（单独运行 `git stash` 效果相同，只是不带标签说明。）
2. `git status`：如预期一样干净。现在可以安心处理紧急任务了。
3. `git stash list`：查看暂存列表，最新的排在最前。
4. 紧急任务处理完毕（假设）。取回之前的工作：`git stash pop`。修改内容重新恢复，且该条暂存记录会被清除。
