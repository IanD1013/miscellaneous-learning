### 日常快捷方式：commit -am

`git commit -a` 会暂存所有已跟踪的修改并一步完成提交。
这是你输入频率最高的一行命令，但它有一个需要注意的盲区：未跟踪的文件不会被包含在内。

1. 编辑应用，然后单行完成提交：`echo // hotfix >> app.js`，接着运行 `git commit -am "quick hotfix"`。
2. `git status`：`ideas.txt` 仍然处于未跟踪状态。`-a` 仅收集已跟踪的更改；全新文件在适用该快捷方式之前需要先执行一次 `git add`。

另外值得了解的是：该环境中没有编辑器，因此 `-m` 始终是必需的。
单独运行 `git commit` 会被礼貌拒绝；如果你好奇的话可以尝试一下。
