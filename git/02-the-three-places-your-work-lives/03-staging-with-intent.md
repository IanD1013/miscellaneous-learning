### 有目的地暂存

`git add` 有三种形式，选择合适的形式就是决定你下一次 commit 要表达的内容。

1. `git add app.js`：单个路径，精准操作。
2. `git add .`：从当前目录向下的所有已修改或未跟踪文件。`notes.md` 和 `styles.css` 会被同时暂存。
3. 删除也算作更改。使用普通 shell 命令 `rm old.txt` 删除文件，然后运行 `git add -A`：删除操作会与其他所有更改一起被暂存。（`rm -f` 是适用于文件可能不存在时的静默选项。）
4. `git status -s`：查看完整的暂存状态全貌。

在这个扁平的单文件夹仓库中，`.` 和 `-A` 覆盖的范围相同；重要的是养成知晓两者都存在的习惯。
