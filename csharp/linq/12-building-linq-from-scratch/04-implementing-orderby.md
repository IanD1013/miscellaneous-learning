### 手动排序：理解 OrderBy 隐藏的底层逻辑

LINQ 的 `OrderBy` 非常方便，但它隐藏了重要的算法操作。
与可以以流式方式逐个处理元素的 `Where` 或 `Select` 不同，**排序从根本上要求在生成任何输出之前查看所有元素**。
`OrderBy` 在内部会将整个序列缓冲到一个数组中，为每个元素计算排序键，然后执行内省排序（introsort，一种快速排序和堆排序的混合算法）来排列它们。
只有在完成所有这些工作之后，它才会产出第一个元素。
理解这一点对于编写性能敏感的代码至关重要：排序的最佳情况也是 O(n log n)，并且全量缓冲意味着它永远无法实现延迟执行。

在本练习中，你将使用**插入排序**（insertion sort）从零开始实现排序。
这是一种简单的基于比较的算法，它每次构建一个元素的数组有序部分。

### 插入排序的工作原理

想象一下你正在整理手中的扑克牌。
你一张一张地拿起牌，对于每张新牌，你都会将它插入到已经排好序的牌中的正确位置。

插入排序的工作方式相同：

1. 从第二个元素（索引 1）开始 - 单个首元素本身就是“有序”的。
2. 取出当前元素（即 "key"），并将其向前与已排序部分进行比较。
3. 将每个比它大的元素向右移动一位以腾出空间。
4. 将 key 插入空出的位置中。
5. 对数组中的每个元素重复此操作。

最坏情况下的时间复杂度为 O(n²)，但它在小型或接近有序的数组上表现良好，并且易于正确实现。

### 语法

```csharp
// 外层循环：从第二个元素遍历到末尾
for (int i = 1; i < array.Length; i++)
{
    // 保存当前元素
    // 内层循环：移动比已保存元素大的元素
    // 将已保存的元素放到正确的位置
}
```

### 示例

以手动按字母顺序排序字符 `['D', 'B', 'A', 'C']` 为例：

```vbnet
开始：    [D, B, A, C]

i=1, key=B:  比较 B < D → 将 D 右移 → 插入 B
              [B, D, A, C]

i=2, key=A:  比较 A < D → 将 D 右移
             比较 A < B → 将 B 右移 → 插入 A
              [A, B, D, C]

i=3, key=C:  比较 C < D → 将 D 右移
             比较 C < B？否 → 插入 C
              [A, B, C, D]
```

请注意数组的左侧部分是如何在每次遍历中逐渐变为有序的，以及 key 是如何通过向右移动较大的相邻元素来“滑动”到合适位置的。

### 常见陷阱

- **忘记保存 key**：如果在移动元素之前没有保存 `array[i]`，该值将被覆盖。
- **差一错误（Off-by-one errors）**：内层循环条件必须检查 `j >= 0` 以避免访问索引 -1。
- **修改输入数组**：考虑是进行原地排序还是返回新数组。在本练习中，请返回一个新的排序数组，以便不修改原始数组。

### 你的任务

编写一个方法，接收一个整数数组，并返回一个包含按升序排序的相同元素的**新**数组。
你必须使用循环手动实现**插入排序**，不能使用 LINQ 排序操作符，也不能使用 `Array.Sort`。

### 方法签名

```csharp
public static int[] SortAscending(int[] numbers)
```

### 预期结果

```scss
SortAscending([3, 1, 4, 1, 5, 9]) → [1, 1, 3, 4, 5, 9]
SortAscending([5, 4, 3, 2, 1])    → [1, 2, 3, 4, 5]
SortAscending([42])               → [42]
SortAscending([])                  → []
```

### 解答

```csharp
using System;

public class Solution
{
    public static int[] SortAscending(int[] numbers)
    {
        // 复制一份新数组，避免修改原始数组
        int[] result = new int[numbers.Length];
        for (int i = 0; i < numbers.Length; i++)
        {
            result[i] = numbers[i];
        }

        // 插入排序：从第二个元素开始
        for (int i = 1; i < result.Length; i++)
        {
            // 先保存 key，避免被覆盖
            int key = result[i];
            int j = i - 1;

            // 将比 key 大的元素向右移动一位
            while (j >= 0 && result[j] > key)
            {
                result[j + 1] = result[j];
                j--;
            }

            // 将 key 插入空出的位置
            result[j + 1] = key;
        }

        return result;
    }
}
```
