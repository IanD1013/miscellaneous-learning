### 保留小数部分转换

天气档案以 `int` 提供摄氏度，而显示界面需要华氏度 `double`。
如果使用整数计算五分之九的比例，小数部分将在公式的其余部分运行之前丢失。

显式类型转换将目标类型放在括号中，直接置于待转换的值之前。
在 `celsius` 前写上 `(double)` 可以在进行算术运算之前将该操作数转换为 double。
位置非常重要：对最终计算出的结果进行类型转换无法恢复已经被丢弃的小数部分。

`/` 标记是一个中缀除法运算符。
它将左操作数除以右操作数。
对于两个整数，整数除法会丢弃小数部分，因此 9 除以 5 会变成 1。
对于像 `9.0` 或 `5.0` 这样的 double 操作数，C 会将混合表达式提升为 double 并保留小数。
提供的类型转换可确保 Celsius 值也作为 double 参与运算。

通过使用 `(double)` 转换 `celsius`、在浮点算术中应用五分之九的比例并加上 32，来实现摄氏度到华氏度的计算。
请使用 double 字面量 `9.0` 和 `5.0`。
强制性的标记检查要求必须进行显式类型转换。

精确的返回值包括 21 转换为 `69.8`，0 转换为 `32`，37 转换为 `98.6`，以及 -40 转换为 `-40`。

### 解答

```c
#include <stdio.h>

double c_to_f(int celsius) {
    // 乘以 9，除以 5，加上 32，且不丢失小数部分
    return (double)celsius * 9.0 / 5.0 + 32;
}
```
