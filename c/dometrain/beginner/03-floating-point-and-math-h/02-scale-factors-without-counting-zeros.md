一家镜片工坊以一百万（1,000,000）为系数将米转换为微米。
规格说明书上的公差范围从 0 到整整 1 米不等。
将该系数写为一长串零会使单字符计数错误难以被察觉。

C 语言提供了几种浮点字面量形式。
小数点使 `1.0` 成为浮点字面量，而指数表示法用 10 的幂来表示同类值。
在 `1e6` 中，`1` 被放大了 10 的 6 次方倍，因此其值为一百万。
无后缀的浮点字面量（如 `1.0` 或 `1e6`）的类型为 `double`，与此处的参数和返回类型相匹配。

实现 `meters_to_micrometers`，将 `meters` 乘以指数形式的 `1e6` 并返回结果。
请务必使用完全相同的拼写来编写该系数，因为 token 检查会搜索 `1e6`。
有两种拼写会被拒绝：十进制的 `1000000`，以及 `1000` 乘以自身（这只是把零的计数分成了两部分）。

要求的返回值如下：

- `0.000002` 米返回 `2`
- `0.00025` 米返回 `250`
- `0.0000125` 米返回 `12.5`
- `1` 米返回 `1000000`
- `0` 米返回 `0`

输入值中的小数点和缩放因子中的指数是表示浮点值的两种源码表示法。
它们本身都不会改变单位；乘法运算执行了实际的转换。

### 解答

```c
#include <stdio.h>

double meters_to_micrometers(double meters) {
    // 1 米等于一百万微米
    return meters * 1e6;
}
```
