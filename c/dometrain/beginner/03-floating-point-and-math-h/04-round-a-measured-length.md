测量交接需要将测量长度保留到两位小数。
该函数必须改变数值本身，而不是仅仅格式化文本。

`math.h` 头文件声明了 C 的标准数学函数。
它的包含指令 `#include <math.h>` 位于源文件顶部附近，在代码调用这些数学函数之前。
初始代码中已经包含了该指令。

有三个函数可以选择不同的舍入方向。
`floor(` 向负无穷大方向向下舍入。
`ceil(` 向正无穷大方向向上舍入。
`round(` 会选择最近的整数，而刚好处于中间的值会舍入到远离零的整数。
测量长度永远不会是负数，因此在这里中间值总是向上舍入。
此测量需要“四舍五入到最近值”的行为，因此请使用 `round`，而不是 floor 或 ceil。

`round` 作用于整数边界。
要保留两位小数，首先将数值乘以 `100.0` 进行缩放，这会将百分位移动到该整数边界。
接着 `round(length_m * 100.0)` 会在缩放后的单位中生成最近的整数值。
最后，`/ 100.0` 恢复米为单位，并将舍入后的数字放回小数点后。

使用这种“缩放、舍入和恢复”的顺序来实现 `rounded_length`。
强制性 token 检查会检查 `round(` 调用本身。
当输入为 7.504 时返回 `7.5`，输入为 7.506 时返回 `7.51`，输入为 0.125 时返回 `0.13`，输入为 12.34 时返回 `12.34`，输入为 0 时返回 `0`。

### 解答

```c
#include <stdio.h>
#include <math.h>

double rounded_length(double length_m) {
    // 先乘以 100.0 缩放，舍入，再恢复为米
    return round(length_m * 100.0) / 100.0;
}
```
