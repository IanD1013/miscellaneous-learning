### 从边长计算误差幅度

矩形框架的预期对角线可以通过其宽度和高度计算得出。
`frame_error` 将该预测值与实测的 `diagonal` 进行比较，并返回一个非负的 `double` 幅度值，用于描述两者之间的差距，无论哪一个更大。

数学函数 `pow` 接受两个参数：底数和指数。
形式为 `pow(side, 2.0)` 的调用会将底数提升到二次方（即平方）。
对 `width` 和 `height` 都使用 `pow(`。

`sqrt` 函数接受一个参数并返回其非负平方根。
将两条边的平方相加并将该和传递给 `sqrt(`，即可得到预测的对角线长度。

最后，`fabs` 计算浮点参数的绝对值。
其结果是一个非负的 `double`，因此用 `fabs(` 包裹实测值与预测值的差值，可以使偏短的对角线和偏长的对角线报告相同的误差幅度。
不要使用整数 `abs`，因为它对于这些 double 值来说是错误的类型。

### 要求

- 使用 `pow` 和指数 `2.0` 来计算每条边的平方。
- 对两个平方的和使用 `sqrt`。
- 用实测对角线减去预测对角线，然后将该差值传递给 `fabs`。
- 边长为 5 和 12、对角线为 13.5 时返回 `0.5`；边长为 3 和 4、对角线为 5 时返回 `0`；边长为 5 和 12、对角线为 12 时返回 `1`；边长为 1.5 和 2、对角线为 4 时返回 `1.5`。

所有这三个调用都是必需的标记：检查机制会在你的代码中搜索 `pow(`、`sqrt(` 和 `fabs(`，因此仅仅提及名称是不够的。

### 解答

```c
#include <stdio.h>
#include <math.h>

double frame_error(double diagonal, double width, double height) {
    // 将实测对角线与勾股定理预测的对角线进行比较
    double predicted = sqrt(pow(width, 2.0) + pow(height, 2.0));
    return fabs(diagonal - predicted);
}
```
