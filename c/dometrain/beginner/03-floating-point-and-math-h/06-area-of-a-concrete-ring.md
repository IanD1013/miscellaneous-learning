本章的综合练习用于计算两个圆形边界之间的混凝土面积。
其声明的定义域为 `0 <= inner_r <= outer_r <= 10000`。
两个半径均为非负数，且内圆必须位于外圆内部，以描述一个实际的圆环。
如果颠倒这种关系，则会从较小的面积中减去较大的面积，从而产生负值而非圆环面积。

### 计算顺序

起始代码提供了 `pi` 为 `3.141592653589793`。
请保留该字面量。
最后一个评分测试用例会对 10000 的半径求平方，这将使 pi 乘以一亿，因此截断为六位或八位的 pi 会在百分位上出现偏差，导致该用例失败，尽管它仍能通过小圆环的测试。
使用 `pow(radius, 2.0)` 对每个半径求平方，将每个平方值乘以 pi，然后从外圆面积中减去内圆面积。
有限的 10000 上界确保了两个平方值以及最终的 double 计算均在有限范围内。
先减去半径描述的是长度，而不是面积。

仅对计算完成后的差值进行四舍五入。
将面积乘以 `100.0`，调用 `round`，然后除以 `100.0`。
先对每个圆进行四舍五入可能会改变最终的百分位结果。

评分器包含普通圆环、半径相等的情况、内半径为零以及外半径达到上限 10000 的情况。
学员代码必须包含 `round(` 调用。
没有失败标记（sentinel）或验证分支；输入已经满足定义域，因此每次调用返回的都是四舍五入后的差值。

### 解答

```c
#include <stdio.h>
#include <math.h>

double ring_area(double outer_r, double inner_r) {
    double pi = 3.141592653589793;
    // 计算圆环面积，然后将最终值四舍五入到两位小数
    double area = pi * pow(outer_r, 2.0) - pi * pow(inner_r, 2.0);
    return round(area * 100.0) / 100.0;
}
```
