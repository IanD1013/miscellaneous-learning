二月通常有 28 天。
闰年判定会多加一天，但世纪年份需要仔细进行逻辑分组。

### 编写日历规则

如果一个年份能被 4 整除且不能被 100 整除，除非它能被 400 整除，那么它就是闰年。
能整除意味着 `%` 的余数为零。
使用 `&&` 连接“能被 4 整除”和“不能被 100 整除”这两个比较条件。
用括号将这对条件组合在一起，然后使用 `||` 连接“能被 400 整除”的例外情况。

分组后的表达式在为 true 时得出 1，为 false 时得出 0。
将该值与 28 相加即可返回 29 或 28，而无需使用分支语句。
学员的代码必须包含 `%`、`&&` 和 `||`；由于每条日历规则都至关重要，因此会强制检查每个运算符。

在完成之前，请检查世纪年份的情况：

- 2024 能被 4 整除但不能被 100 整除，因此返回 `29`。
- 2023 两种情况均不满足，因此返回 `28`。
- 1900 能被 100 整除但不能被 400 整除，因此返回 `28`。
- 2000 能被 400 整除，因此返回 `29`。
- 2100 是另一个非闰年的世纪年份，返回 `28`。
- 1996 遵循普通的“能被 4 整除”规则，返回 `29`。

`february_days` 会返回该天数。
这是本课程中唯一的闰年练习；请在一个分组运算符表达式中完成所有逻辑，而不是引入后续才会学到的控制流结构。

### 解答

```c
// 二月有 28 天，除非闰年规则另有规定
int february_days(int year) {
    return 28 + ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0);
}
```
