### 记录每次票务事件

售票处初始有 `stock` 张票。
三次售票各售出一张票，随后一次退票退回一张。
声明的输入范围是 2 到 2147483647。
即使在下边界，三次递减后也仅达到 -1，之后退票将该值提升至 0。
在上边界，最终结果为 2147483645。
因此，每个可表示的中间值和返回值都适合存储在 `int` 中。

递增运算符 `++` 会将变量存储的值精确增加 1。
递减运算符 `--` 会将其精确减少 1。
请使用前缀形式（即运算符位于变量之前），并将每个操作放在以分号结尾的独立语句中。
在更大的表达式中，前缀递增或递减还会产生一个表达式结果。
在这里，该表达式结果会被丢弃；只有对存储值的更新才重要。

### 需求

- 对 `stock` 执行三次前缀递减运算，每次售票执行一次。
- 针对退票执行一次前缀递增运算。
- 返回最终的 `stock` 值。
- 请勿编写 `stock - 2` 或不带空格的紧凑写法。根据 token 规则，禁止使用这两种净变化快捷方式。
- 为每个符合约定的输入（包括两个数值边界）保留这四次可见的更新。

函数参数是该调用的局部变量，因此在该函数内部修改 `stock` 是合法的。

### 解答

```c
// 售出三张票，退回一张；每次事件单独更新一次计数
int roll_remaining(int stock) {
    --stock;
    --stock;
    --stock;
    ++stock;
    return stock;
}
```
