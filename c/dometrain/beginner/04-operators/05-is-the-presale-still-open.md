### 依然包含在内的边界

预售在截止日当天本身依然保持开放。
`presale_open` 接收今天的日期编号和截止日期，然后直接返回一个真值。
两个参数都被声明为 1 到 366 之间的日期编号，因此普通的比较操作即可覆盖调用者可能传入的所有情况。

比较表达式的计算结果为 `true` 或 `false`。
严格比较 `<` 表示小于且不包括相等，而 `<=` 表示小于或等于且包含边界。
相反的顺序使用 `>` 表示大于，`>=` 表示大于或等于。
`==` 测试相等性，而 `!=` 测试不等性。
这六个运算符中的每一个都会产生一个 bool 结果；没有一个会进行赋值。

`stdbool.h` 头文件提供了 bool 类型以及易读的常量 `true` 和 `false`。
它的包含指令是 `#include <stdbool.h>`，已经放置在函数上方。
`bool` 返回类型告诉调用者返回的值是一个真值。

对于这个截止日期，直接返回比较表达式本身。
今天在截止日期之前或等于截止日期返回 true；今天在截止日期之后返回 false。
禁止使用 `if (` 或 `if(` 标记，因为比较本身就是答案。

预期结果：对于 `(120, 200)` 和 `(200, 200)` 为 true，对于 `(201, 200)` 和 `(300, 31)` 为 false。
刚好在截止日期当天的情况区分了 `<=` 与严格比较 `<`。

### 解答

```c
#include <stdbool.h>

// 在截止日当天下的订单仍然有效
bool presale_open(int today, int deadline) {
    return today <= deadline;
}
```
