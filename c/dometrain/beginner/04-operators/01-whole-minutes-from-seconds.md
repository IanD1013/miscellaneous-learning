舞台日志以开门后的整秒数记录节目的开始和结束时间。
制作团队希望得到以整分钟为单位的持续时间，剩余的秒数应直接舍去而不是四舍五入。

该计算在单个表达式中使用了多个算术运算符。
运算符优先级提供了默认的计算顺序，但使用括号将计算耗时的减法组合起来可以使预期的顺序更加清晰。
左括号 `(` 和右括号 `)` 确保 `end_seconds - start_seconds` 在 `/` 执行除法之前完成。
这里的 `-` 表示减法，`/` 表示除法。

因为 `/` 两侧都是整数操作数，所以 C 执行整数除法。
结果是一个整数商，任何小数部分都会通过向零截断而被舍弃。
这与可以保留小数结果的浮点除法不同。
例如，150 除以 60 得到的整分钟商为 2，而不是将 2.5 四舍五入为 3。

声明的输入范围为 `0 <= start_seconds <= end_seconds <= 2147483647`。
这两个时间戳都是从开门那一刻起正向计数的，因此都不是负数，而且没有任何节目会在开始之前结束。
在这些范围内相减得到的差值范围为 0 到 2147483647，这是可表示的，因此组合减法本身不需要进行范围检查。

通过用结束时间减去开始时间、将该差值用括号组合、然后除以 60 来实现 `elapsed_minutes`。
评分系统期望 `(0, 150)` 返回 2，`(40, 400)` 返回 6，`(0, 59)` 返回 0，以及两个时间都是 30 时返回 0。
该取值范围上限有两个测试用例：`(0, 2147483647)` 返回 35791394，`(2147483000, 2147483647)` 返回 10。

### 解答

```c
// 只保留整分钟，剩余秒数直接舍去
int elapsed_minutes(int start_seconds, int end_seconds) {
    return (end_seconds - start_seconds) / 60;
}
```
