发车时刻表显示的分针范围为 0 到 59。
当非负延迟使其超过 59 时，结果必须循环绕回到该范围的起始位置。

取模运算符 `%` 返回整数除法的余数。
在这里，延迟是一个非负被除数：将其除以 60 可以去除整小时数，并留下 0 到 59 的余数。
在有界相加之后进行第二次取模操作，以对显示的分针进行循环回绕。

本课声明的输入范围为：`current_minute` 在 0 到 59 之间，`minutes_ahead` 在 0 到 2147483647 之间。
在上边界附近直接将这些输入相加会有发生有符号整数溢出的风险。
请先使用 `% 60` 缩减 `minutes_ahead`。
其余数至多为 59，因此将其与 `current_minute` 相加最多产生 118。
该有界相加不会溢出。
对总和再次应用 `% 60` 以完成最终的回绕。

按照该安全顺序实现 `wrapped_minute`：缩减延迟，将有界值相加，然后对结果进行回绕。
强制标记检查要求使用 `%`；重复减法并不是本题要求的机制。
常规情况下依然满足：50 加 25 返回 15，59 加 1 返回 0。
在输入范围边界处，当前分钟为 59 且延迟为 2147483647 时返回 6。

### 解答

```c
// 显示板从 0 显示到 59，然后重新开始
int wrapped_minute(int current_minute, int minutes_ahead) {
    // 先缩减延迟，再做有界相加，最后回绕
    return (current_minute + minutes_ahead % 60) % 60;
}
```
