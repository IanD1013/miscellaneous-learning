图像通道是一个字节，其取值范围为 0 到 255。
函数约定提供该范围内的值（包括 200 和 255），并期望存储的值原样返回。

当普通整型同时表示负值和正值时，它是有符号的。
添加 `unsigned` 则会选择非负范围。
在本课程平台上，`unsigned char` 占用一个字节，可以表示从 0 到 255 的每个值。
普通的 `char` 可能是有符号的，因此无法保证覆盖完整的通道范围。

在 `channel_byte` 内部，声明一个 `unsigned char` 变量并使用 `value` 对其进行初始化。
将该变量作为函数的 `int` 结果返回。
由于所有符合约定的通道值都能容纳，因此转回 `int` 时会保留每一个值。

评测系统会检查以下返回值：

- `channel_byte(200)` 返回 `200`
- `channel_byte(128)` 返回 `128`
- `channel_byte(0)` 返回 `0`
- `channel_byte(255)` 返回 `255`

强制 token 检查要求使用由两个单词构成的类型 `unsigned char`，因为单独使用 `unsigned` 也可以接受非单字节的更宽类型。
小于 0 或大于 255 的值超出了本练习的输入约定，因此请勿添加范围限制（clamping）或验证。
此处的关键在于存储类型，而在该平台上，普通 `char` 在 200 和 255 的测试用例中会失败，因为它的字节是有符号的。

### 解答

```c
int channel_byte(int value)
{
    // 用恰好占一个字节的类型存储 value，然后返回
    unsigned char channel = value;
    return channel;
}
```
