### 以字节形式存储的两个字母

BMP 文件以字母 B 和 M 开头。
检查器将这两个魔数（magic bytes）与一个整数 `salt` 结合起来生成一个小的校验和。

在 C 语言中，`char` 是一种用于单字节大小值的整型类型。
存储在 char 变量中的值可以参与普通的整数运算，因此这两个存储的字母可以与 `salt` 相加。
在课程平台上，它们的值之和为 143。

将每个字母写为字符字面量。
字符字面量将单个字符放在单引号中，例如 `'B'`，并以整数值表示该字符。
单引号非常重要：双引号会创建字符串字面量。
请让编译器提供数值编码，而不是手动输入十进制形式。

为 `salt` 声明的数值范围是 -2147483648 到 2147483504。
加上字符之和后，将生成一个介于 -2147483505 到 2147483647 之间的可表示校验和。
在 `header_checksum` 内部，为每个字母声明一个 `char` 变量，然后返回它们的和加上 `salt`。
不要硬编码任何一个字节码或它们预先计算的和；词法检查禁止使用这些捷径。

负数 salt 会正常相减，评分系统会固定该范围的两端：约定的最低 salt 返回 -2147483505，而上限则刚好达到 `INT_MAX`。
评分系统会检查返回的整数，不包含控制台输出。

### 解答

```c
int header_checksum(int salt)
{
    // 先把两个魔数字母存入 char 变量，再做加法
    char first = 'B';
    char second = 'M';
    return first + second + salt;
}
```
