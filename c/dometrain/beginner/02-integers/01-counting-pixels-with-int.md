缩略图生成器在后续工作使用图像尺寸之前，需要获取图像中的像素数量。
`pixel_count` 接收 0 到 46340 之间的整数宽度和高度值，将它们相乘，并返回总数。

本练习介绍了变量，一个具名的存储单元。
声明会为该存储单元指定类型和名称。
在 `int total = value;` 中，`int` 是类型，`total` 是名称，`=` 引入初始化器，而 `;` 结束声明语句。
初始化变量意味着在声明变量的同时赋予其第一个值。
初始化器可以是一个使用参数的表达式。

在声明的数值范围内，可表示的最大乘积为 `46340 * 46340`，即 2147395600，该值可以放入 `int` 中。
声明 `int total` 并在同一语句中将其初始化为宽度乘以高度的结果。
然后 return `total`。
Token 检查会查找名为 `total` 的声明；在声明处直接赋予其初值是本练习所讲授的形式。

评分器包含普通图像尺寸、零尺寸以及最大平方 `(46340, 46340)`。
零尺寸的情况由乘法直接得出，不需要任何分支判断。

### 解答

```c
int pixel_count(int width, int height)
{
    // 声明名为 total 的 int，用像素计算结果初始化，然后返回
    int total = width * height;
    return total;
}
```
