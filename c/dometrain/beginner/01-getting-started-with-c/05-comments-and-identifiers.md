C 语言有两种注释形式。
单行注释以 `//` 开头，并在下一个换行符处结束。
块注释以 `/*` 开头，并跨行延续，直到匹配的 `*/` 为止。
编译器会忽略这两种注释中的每一个字符。
在初始代码中，块注释覆盖了 `return code;`，这使得占位用的 `return 0;` 成为函数体中唯一生效的语句。

解除真正语句周围的注释并删除占位符，使唯一的有效 return 语句将传入的 `code` 原样返回。
这意味着 `room_code(7)` 返回 7，`room_code(0)` 返回 0，而 `room_code(-3)` 返回 -3。
完成后的函数绝不能包含 `return 0`：该标记是占位符，必须被移除。
评分程序会检查返回的整数。

此文件中的名称都是标识符。
C 语言的标识符可以包含字母、数字和下划线字符 `_`。
它不能以数字开头，并且不允许使用连字符，因为 C 语言会将连字符视为运算符。
