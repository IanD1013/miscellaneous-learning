这个徽章中没有任何新语法结构。
唯一的新要求是打印出的六行必须遵循统一的排版格式，并且其中一个值是通过计算得出而不是直接传入的。
`print_badge` 接收一个姓名、徽章编号和活动年份。
声明的年份范围是 0 到 2147483646，因此 `year + 1` 可以达到 2147483647 而不会使 `int` 溢出。
该函数负责打印；它不返回徽章字符串。

### 徽章排版

对于 `Ada`、徽章 17 和年份 2026，捕获的输出必须完全如下：

```yaml
====================
DevConf 2026 badge
Name: Ada
Badge: 17
See you in 2027!
====================
```

第一行和第六行各包含恰好二十个 `=` 字符。
对每个数字使用 `%d`，对姓名使用 `%s`。
在最后一个 `%d` 需要值的位置传入安全的表达式 `year + 1`。

### 要求

- 严格按照显示的顺序打印六行，不得包含额外的标签或空行。
- 保持固定的大小写、空格、冒号位置以及末尾的感叹号。
- 将传入的 `year` 放在第二行，`name` 放在第三行，`badge_number` 放在第四行。
- 根据参数计算下一年，包括 2147483646 递增到 2147483647 的上界情况。
- 徽章编号为零时必须打印为 `0`。
- 空姓名必须在 `Name:` 之后和换行符之前保留固定的分隔空格。`%s` 不提供任何字符，但 `Name: %s\n` 仍会输出 `Name: ` 和换行符。该空格会被严格评分。
- 姓名为 `%%` 时打印 `Name: %%`。姓名是传递给 `%s` 的值，绝不能直接用作格式化字符串本身。
- 禁止使用 `puts` 和 `stdout` 流，因此每一行都必须通过 `printf` 输出。

在这里可以使用多次 `printf` 调用，调用的顺序决定了行的顺序。
六行之间的五个换行符将被比对；底框之后的末尾换行符在比对前会被去除，因此加不加都不会产生影响。
评分系统读取的是标准输出，而不是返回值。

### 解答

```c
#include <stdio.h>

// 共六行；上下边框各为 20 个等号
void print_badge(const char *name, int badge_number, int year) {
    printf("====================\n");
    printf("DevConf %d badge\n", year);
    printf("Name: %s\n", name);
    printf("Badge: %d\n", badge_number);
    printf("See you in %d!\n", year + 1);
    printf("====================\n");
}
```
