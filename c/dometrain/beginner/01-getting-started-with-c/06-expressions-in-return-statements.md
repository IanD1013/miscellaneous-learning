### 大厅的单一表达式

主大厅设有按排排列的常规座位，以及一个单独的无障碍区域。
`hall_seats` 接收 `rows`、`seats_per_row` 和 `accessible_seats`（每个取值范围均为 0 到 10000），并返回它们的总容量。

`return` 语句可以直接包含算术表达式，而不必使用存储的变量名。
在 `a * b + c` 中，`*` 是位于其左操作数与右操作数之间的中缀运算符。
它会在中缀运算符 `+` 执行加法之前先执行乘法。
在声明的数值范围内，可表示的乘积最大为 100000000。
加上无障碍座位后，可表示的结果不会超过 100010000，完全处于 `int` 的安全范围内。

直接在 `return` 之后编写计算式，并以 `;` 结束该语句。
不要声明中间变量，也不要使用赋值，因此禁止使用 `=` 符号。
该表达式必须先将 `rows` 乘以 `seats_per_row`，然后加上 `accessible_seats`。

预期返回值包括：

- 12 排，每排 10 个座位，以及 6 个无障碍座位：`126`
- 0 排，每排 25 个座位，以及 4 个无障碍座位：`4`
- 上边界 `(10000, 10000, 10000)`：`100010000`

### 解答

```c
// 排数乘以每排座位数，再加上无障碍座位，用一个表达式返回
int hall_seats(int rows, int seats_per_row, int accessible_seats) {
    return rows * seats_per_row + accessible_seats;
}
```
