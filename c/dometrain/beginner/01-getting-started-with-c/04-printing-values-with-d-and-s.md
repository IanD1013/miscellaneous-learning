### 将值与占位符匹配

签到处会使用字符串 `name` 和整数 `badge_number` 调用 `print_badge_line`。
该函数必须打印一行内容，例如 `Badge 17: Ada`。

`printf` 的第一个参数是格式化字符串。
该字符串内部的占位符用于标记后续参数写入的位置。
`%d` 接收下一个 `int` 并将其显示为十进制数字。
`%s` 接收下一个字符串并显示其字符。
`printf` 从左到右将占位符与后续参数进行匹配，因此参数顺序必须与占位符顺序保持一致。
对于这一行，徽章编号紧跟在格式化字符串之后作为第一个参数，姓名作为第二个参数。

使用包含这两个占位符的单个格式化字符串构建该行。
保留它们周围的字面量部分 `Badge ` 和 `: `，并以 `\n` 结尾，以便下一个徽章从新的一行开始。
可见的输出必须为：

- `name` 为 `Ada`，`badge_number` 为 `17`：`Badge 17: Ada`
- `name` 为 `Grace Hopper`，`badge_number` 为 `204`：`Badge 204: Grace Hopper`
- `name` 为 `Bo`，`badge_number` 为 `0`：`Badge 0: Bo`
- 空字符串且 `badge_number` 为 `7`：`Badge 7:` 后跟固定的分隔空格；`%s` 不提供任何姓名字符，但它不会移除前面的那个空格
- `name` 为 `%%` 且 `badge_number` 为 `5`：`Badge 5: %%`；这两个百分号是姓名内部的字符，`%s` 会原样输出它们，而不是将它们解析为占位符

最后一种情况正是为什么姓名应该放在 `%s` 对应的参数位置，而绝不能直接放在格式化字符串的位置。
这里禁止使用 `puts` 和 `stdout` 流，因此整行输出都应通过 `printf` 完成。
自动评分系统会逐字符比对捕获的行（末尾换行符除外，评分系统会先去除两端的换行符）。

调换 `%d` 和 `%s` 的位置，或者以错误的顺序放置后续参数，都会使每个占位符接收到错误类型的值，从而无法满足函数约定的要求。

### 解答

```c
#include <stdio.h>

// 每个徽章一行：先打印编号，再打印姓名
void print_badge_line(const char *name, int badge_number) {
    printf("Badge %d: %s\n", badge_number, name);
}
```
