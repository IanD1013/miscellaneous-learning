### SERIAL 和 IDENTITY

自增列会自动为每一行新数据生成唯一的连续值，从而无需在插入时手动指定 ID。

### SERIAL 类型

PostgreSQL 提供了三种 SERIAL 类型，它们是创建自增整数列的快捷方式：

```sql
-- SERIAL：4 字节整数（1 到 2,147,483,647）
CREATE TABLE products (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100)
);

-- BIGSERIAL：8 字节整数（1 到 9,223,372,036,854,775,807）
CREATE TABLE events (
    id BIGSERIAL PRIMARY KEY,
    event_name VARCHAR(100)
);

-- SMALLSERIAL：2 字节整数（1 到 32,767）
CREATE TABLE categories (
    id SMALLSERIAL PRIMARY KEY,
    name VARCHAR(50)
);
```

### GENERATED AS IDENTITY（SQL 标准）

现代且符合 SQL 标准的方法是使用 `GENERATED AS IDENTITY`：

```sql
-- GENERATED ALWAYS：数据库始终自动生成该值
CREATE TABLE customers (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name VARCHAR(100)
);

-- GENERATED BY DEFAULT：必要时允许手动覆盖
CREATE TABLE invoices (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    amount NUMERIC(10,2)
);
```

### SERIAL 与 IDENTITY 对比

| 特性 | SERIAL | GENERATED AS IDENTITY |
| --- | --- | --- |
| SQL 标准 | 否（PostgreSQL 特有） | 是 |
| 是否可覆盖值 | 是（始终可以） | ALWAYS: 否, BY DEFAULT: 是 |
| 语法 | 更简洁 | 更明确 |

### 插入数据

使用自增列时，可以省略 ID 列：

```sql
-- id 会被自动分配
INSERT INTO products (name) VALUES ('Widget');
INSERT INTO products (name) VALUES ('Gadget');
-- 结果：Widget 的 id 为 1，Gadget 的 id 为 2
```

### 你的任务

创建一个名为 `orders` 的表，包含以下列：

- `id`：使用 SERIAL 的自增主键
- `customer_name`：最多 100 个字符的可变字符字段，不能为 NULL
- `order_date`：DATE 类型，默认值为当前日期（使用 `CURRENT_DATE`）
- `total_amount`：精度为 10、标度为 2 的 NUMERIC 类型

### 预期表结构

| 列名 | 类型 | 约束 |
| --- | --- | --- |
| id | integer (serial) | PRIMARY KEY |
| customer\_name | varchar(100) | NOT NULL |
| order\_date | date | DEFAULT CURRENT\_DATE |
| total\_amount | numeric(10,2) | - |

### 解答

```sql
-- 创建带有自增 id 的 orders 表
CREATE TABLE orders (
    id SERIAL PRIMARY KEY,
    customer_name VARCHAR(100) NOT NULL,
    order_date DATE DEFAULT CURRENT_DATE,
    total_amount NUMERIC(10,2)
);
```
