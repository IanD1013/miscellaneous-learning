### MOD 与整数除法

PostgreSQL 提供了两种处理整数除法的基本操作：

- **MOD(a, b)** 或 **a % b**：返回 `a` 除以 `b` 时的余数
- **整数除法 (a / b)**：当两个操作数都为整数时，返回商（整数结果）

### MOD 函数语法

```sql
-- 使用 MOD 函数
SELECT MOD(17, 5);  -- 返回 2（17 = 5 × 3 + 2）

-- 使用 % 运算符（等价）
SELECT 17 % 5;      -- 返回 2

-- 常见用法：检查偶数或奇数
SELECT MOD(10, 2);  -- 返回 0（偶数）
SELECT MOD(7, 2);   -- 返回 1（奇数）
```

### 整数除法

```sql
-- 整数除法向零截断
SELECT 17 / 5;      -- 返回 3（而不是 3.4）
SELECT 20 / 4;      -- 返回 5

-- 要得到小数结果，需转换为 NUMERIC
SELECT 17.0 / 5;    -- 返回 3.4
SELECT 17 / 5.0;    -- 返回 3.4
SELECT CAST(17 AS NUMERIC) / 5;  -- 返回 3.4
```

### MOD 与除法的关系

```sql
-- 对于任意整数 a 和 b（其中 b ≠ 0）：
-- a = (a / b) * b + (a % b)

SELECT 17 / 5 AS quotient,    -- 3
       17 % 5 AS remainder;   -- 2
-- 验证：3 × 5 + 2 = 17 ✓
```

### 实际应用

| 应用场景 | 表达式 | 结果含义 |
| --- | --- | --- |
| 检查奇偶性 | `n % 2` | 0 = 偶数，1 = 奇数 |
| 检查整除性 | `n % d` | 0 = 可整除 |
| 循环取值 | `n % cycle_length` | 在循环中的位置 |
| 批量分组 | `n / batch_size` | 批次编号 |

### 你的任务

你有一个名为 `numbers` 的表，其中包含各种整数值。
编写一个查询：

1. 选择 `number` 列
2. 创建一个名为 `is_odd` 的列：如果数字是偶数（能被 2 整除），则显示 `0`；如果数字是奇数，则显示 `1`
3. 将结果按 `number` 升序排序

**注意：** 直接使用 `% 2` 即可得到所需结果，它对偶数返回 0，对奇数返回 1！

### 期望的列

- `number`：原始数字
- `is_odd`：`0`（偶数）或 `1`（奇数）

### 期望的结果

```diff
number | is_odd
-------|-------
-4     | 0
0      | 0
1      | 1
2      | 0
7      | 1
12     | 0
15     | 1
100    | 0
```

### 解答

```sql
-- 使用 MOD 判断每个数字是偶数还是奇数
-- 返回列：number, is_odd（偶数为 0，奇数为 1）
-- 按 number 升序排序

SELECT number, MOD(number, 2) AS is_odd
FROM numbers
ORDER BY number;
```
