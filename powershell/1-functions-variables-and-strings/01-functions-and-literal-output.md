函数为一段代码赋予名称，以便你可以再次运行它。
下面是一个生成文本 `Open` 的函数：

```powershell
function Get-Label {
    'Open'
}

Get-Label
```

以 `function` 开头，然后写出名称 `Get-Label`。
连字符属于名称的一部分。
大括号 `{` 和 `}` 标记了函数体的开始和结束：即调用时运行的代码。
定义函数使其可用，但此时尚未运行该代码。

要调用该函数，请在单独的一行中编写 `Get-Label`，如定义下方所示。
PowerShell 会运行函数体并生成 `Open`。

`'Open'` 两侧的单引号标记了文本的开始和结束。
这是一个字面量，即直接写在代码中的值。
请将两个引号保持在同一行。
最终生成的文本不包含引号。

表达式是生成值的代码。
在这里，`'Open'` 是一个表达式。
由于它是独立存在的，PowerShell 会将该值作为函数的输出发送。
这就是**隐式输出**。
每个独立存在的表达式都会产生输出，即使是在最后一行之前的表达式也是如此。

### 完成函数

初始代码中已经定义了 `Get-Text`。
在其大括号之间添加一个文本字面量表达式，以精确生成 `Ready`。
请注意大小写，不要包含多余的空格或输出。

在编辑器中仅保留函数定义。
选择 **Run** 进行尝试：系统将调用你的函数，并将其输出与 `Ready` 进行对比。
满意后，选择 **Submit**。

### 解答

```powershell
function Get-Text {
    # 单独的字面量表达式会作为函数的输出
    'Ready'
}
```
