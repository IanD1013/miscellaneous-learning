变量为存储的值赋予了一个名称，以便你可以在计算中使用它。
在这里，两个赋值语句在函数内部存储了数字：

```powershell
function Get-Difference {
    $first = 9
    $second = 4
    $first - $second
}
```

`$` 前缀表示一个变量：`$first` 和 `$second` 是它的名称。`=` 运算符将其右侧的值存储在左侧的变量中。
编写像 `9` 这样的数值时不要加引号，这样计算才会将其作为数字处理。

赋值操作不会输出它存储的值。
最后一行读取这两个变量，并使用 `-` 从第一个值中减去第二个值。
作为函数内部的一个纯表达式（bare expression），它会输出 `5`。
颠倒这些变量将产生 `-5`。

算术运算还包括使用 `+` 进行加法、使用 `*` 进行乘法以及使用 `/` 进行除法。
这些函数展示了相同的输出表达式模式：

```powershell
function Get-Total {
    9 + 4
}

function Get-Product {
    3 * 4
}

function Get-Quotient {
    8 / 2
}
```

它们分别输出 `13`、`12` 和 `4`。
在 `8 / 2` 中，`/` 后面的数字是除数；除法运算请使用非零除数。

在起始代码中完成 `Get-Difference`。
它不接受任何参数。
为了练习，请在函数内部将 `18` 和 `7` 分别赋给两个变量，然后输出第一个值减去第二个值的结果。
该函数应该只输出数字 `11`。

### 解答

```powershell
function Get-Difference {
    # 赋值不会产生输出
    $first = 18
    $second = 7
    # 单独的表达式输出差值
    $first - $second
}
```
