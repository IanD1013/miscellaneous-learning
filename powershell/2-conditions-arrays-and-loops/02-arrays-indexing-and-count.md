数组可以将多个值保存在同一个变量中。
先从两个数字开始：

```powershell
$values = @(3, 8)
```

数组表达式 `@()` 会将圆括号内的值收集到一个数组中。
逗号用于分隔其中的元素（即各个单独的值）。
在这里，`$values` 包含 `3` 以及随后的 `8`。
无论包含零个、一个还是多个元素，形式都是一样的。

要选择第一个元素，请使用索引（用于标识其位置的数字）：

```powershell
$values = @(3, 8)
$values[0]
```

这会输出 `3`。
方括号 `[` 和 `]` 会使用它们之间的索引来选择一个元素。
数组索引是从零开始的：第一个元素的索引是 `0`，第二个元素的索引是 `1`。
此示例可以读取索引 `0`，因为该数组包含两个元素。
空数组没有可读取的第一个元素。

要获取元素的数量，请读取 `Count`：

```powershell
$values = @(3, 8)
$values.Count
```

这会输出 `2`。
点号用于访问属性（属于该数组的命名值）。
它的 `Count` 属性给出了元素的数量。
这里的最后一个索引是 `1`，而数量是 `2`。

空数组使用相同的表达式，只是内部没有任何内容：

```powershell
$values = @()
$values.Count
```

这会输出 `0`。
对于 `@(8)`，数组包含一个元素，`Count` 为 `1`。
计数取决于存在多少个元素，与它们的值无关。

### 完成 Get-Size

完成提供的 `Get-Size` 函数。
它的 `$values` 参数接收一个整数数组。
使用其 `Count` 属性输出一个数字：该数组包含多少个元素。
将所有演示表达式留在函数外部，以免它们产生额外的输出。

练习的输入包含零到六个元素，每个元素在 `0` 到 `20` 之间。
这些是本任务的输入范围。
数组可能为空，因此请在不选择特定元素的情况下对其进行计数。

### 解答

```powershell
function Get-Size {
    param($values)
    # Count 属性给出元素数量，空数组也适用
    $values.Count
}
```
